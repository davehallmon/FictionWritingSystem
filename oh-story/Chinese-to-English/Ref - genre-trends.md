# Web-Fiction Genre Trends and Subgenre Reference
A quick-reference guide to genre selection, subgenre writing, and rankings scans.

---

## Writing High-Concept Fiction

### From Idea to Book

1. Find an idea (embryonic special advantage / image / entry point).
2. Assess its potential (fully original? market groundwork?).
3. Match it to a genre (test it inside a familiar genre).
4. Distill the core selling point (can it become an emotional gap or anticipation?).
5. Organize the story embryo (framework / special advantage / entry point).
6. Begin writing to validate it.

### Innovating the Special Advantage

Foundation = satisfy a condition → receive feedback. Variants: multiple conditions and one response / staged feedback / probabilistic feedback / stackable feedback.

### Sustaining Length

1. Find multiple angles on the core selling point, group them into distinct conflict patterns, and give each pattern 1–2 volumes.
2. Stack frameworks: interwoven cycles from multiple angles can support millions of Chinese characters.
3. Framework + small plot loops: large goal → medium goal → small goal → detailed outline.

### Trend-Following = Reskinning

Move the core premise into a familiar genre. Special-advantage stories are compatible with every genre. When following a trend within the same genre, retain the underlying emotion but approach it from another angle.

## Genre Selection

Use 85% familiarity + 15% surprise. Choose a field with adequate data and room to construct a complete world.

## Three Circles of Boundaries

| Circle | Examples | Rule |
|------|------|------|
| Genre circle | Urban, fantasy, xianxia | Broad category |
| Subgenre circle | Extreme-path, mortal-progression, farming | Subdivision |
| Core-premise circle | Specific selling point / special advantage / emotional point | Content must not leave this circle |

| Error | Consequence |
|------|------|
| High-martial-arts fiction becomes bureaucratic politics | Breaks the boundary |
| Farming fiction becomes deep corporate warfare | Flavor contamination |
| Suspense fiction removes suspense | Core selling point disappears |

## Rankings Scans

### Three-Level Classification

| Level | Frequency | Key point |
|------|------|------|
| New genre | Extremely rare | Mark as a trend only when repeated samples appear across rankings and authors; otherwise retain as an observation |
| New special advantage | Relatively rare; usually refurbishment | Suitable for low-cost validation, but change the genre shell and emotional trigger |
| New gimmick | Common | High homogenization risk; lower priority without a differentiating mechanism |

### Methods by Site

**Qidian**: Sanjiang → first-subscription chart → top 15 signed new books → break down books between premium and 10,000 subscriptions.
**Tomato Novel**: Scroll to the bottom of the new-book ranking → use 300,000+ current readers as the standard.

### Popular Qidian Genres

| Genre | Key points |
|------|------|
| Urban | Rebirth / farming / entertainment; rebirth can combine with any element |
| Fantasy | Prioritize strong-feedback samples such as extreme-path and point-allocation domination; mark traditional fantasy high-risk if recent samples are sparse |
| Xianxia | First inspect recent samples using high-concept fusion; purely traditional approaches require additional audience validation |
| Historical | Qin / Tang / Ming / Song / Three Kingdoms; fan-fiction-like approach |
| Infinite Worlds | Use fan fiction rather than original instances |
| Science fiction | Apocalypse stories, including high-concept/farming/game settings |

## Subgenre Writing Essentials

| Subgenre | Core points |
|------|----------|
| Extreme-path | Allocate special-advantage attributes and overwhelm all opposition; clear boundaries and low validation cost make it a low-complexity candidate |
| Mortal progression | An ordinary person climbs through careful calculation; quantified combat power + lifespan drive |
| Wizard | Knowledge system + experimental exploration and advancement; higher barrier to entry |
| Farming | Operate a restaurant/bookstore/fishery, etc.; relatively low complexity and compatible with travel between worlds, but still requires sample validation |
| Urban high martial arts | Common: martial-arts school + academic-school lines / best-friend comparison / senior-sister temptation / showing off in mock exams; the first three chapters of *Martial Saint* are a gold-standard template |
| Fan fiction | Use only when the user names a target IP, the platform permits it, and recent samples remain valid. By default extract only the structure “known world + new variable + rewritten iconic scene” |
| Ranking/list fiction | Low difficulty; find the right entry point |
| Simulation fiction | Simulation creates an emotional gap → reward received → real-world fulfillment |
| Travel between two worlds | Standard template: special advantage + astonishing historical figures + changing destiny |
| Historical | Qin/Tang/Ming/Song/Three Kingdoms dominate; needs crisis, growth from small to large, and a clear main line. Review risk is higher after the Song dynasty |

## Urban Rebirth Fiction

| Dimension | Key points |
|------|------|
| Career/romance ratio | 50:50 has the highest ceiling but demands exceptional execution; weak romance → 80:20, strong romance → begin at 20:80 |
| Anticipation | Without a progression line, sustain anticipation continuously; use suspense reversals sparingly; preserve continuity across a 20,000-character plan |
| Short-video influence | Include several amusing moments per chapter; build a positive-feedback interpersonal network that cycles recurring jokes; readers tolerate repetition of the same joke |
| Homogenization | A slightly innovative opening + solid conventional content can make a premium work; the missing factor is traffic, not content |

## Light Novels

The core is selling dramatic character concepts, especially attractive female-character designs.

- Career line: the heroine's current predicament + her grievances with others
- Romance line: dramatic development + events generated by character pairing
- Core competitiveness: character design + whether the interaction state is enviable

---

## Comedy/Absurdist Fiction

Patterns: falling into a trap + unintended consequences / foolish antagonist / misunderstanding and displacement; these may be combined.
Underlying principle: use reader affinity toward a character to make the plot attack sources of fear or concern around that character.

---

## Dominant-CEO Romance (Women's Fiction)

| Dimension | Traditional | Modern |
|------|------|------|
| Heroine | Naive innocent | Independent professional woman |
| Meeting logic | Chance meeting through an act of kindness | Professional intersection + unique value |
| Hero's convenience | Comprehensive caretaking | Emotional value + enhancement of an already strong life |
| Underlying logic | Marry a good man and need not work | I am strong + I won the heart of someone powerful |

Avoid the traditional “scheming green-tea woman” model for romantic-rival antagonists.

## Naming Patterns

### Short-Form Formula

`[极端事件] + [被逼/死亡] + [反击手段]`

High-frequency terms: went mad/went on a rampage/went mad with regret (17 occurrences) | I countered/I made him (4) | the whole family/everyone (4) | Qingming Festival/April Fools' Day/New Year's Eve (4)

### Long-Form Formula

High-frequency terms: quick transmigration, system, love at first sight, after divorce, antagonist, instant kill at the opening.

### Zhihu Style

Average: 7.9 Chinese characters. Types: event-based / contrast-based / interactive.
