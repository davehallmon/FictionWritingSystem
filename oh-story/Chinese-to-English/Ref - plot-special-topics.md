## Deconstructing Special Advantages and Preventing Power Collapse

### Deconstruct the Special Advantage

**Action**: Break the special advantage into the following elements and recombine them; do not treat it as indivisible.

| Element | Function | Example |
|------|------|------|
| Interface | Clear goals and the most intuitive source of gains | Numbers / levels / progress bars |
| No regression | Improvements earned through repeated action are permanent | Proficiency never decays |
| Repeated improvement | Core loop mechanism | Do A -> gain B -> continue doing A |

**Recombination**: Freely combine the separated elements. For example, “kill monsters + proficiency” = demon-slaying progression; “collect + improve quality” = Flame Mantra / Heavenly Flame progression.

**Core warning**: If the special advantage retains only “quality improvement” late in the story, the sense of progression disappears. Keep several dimensions growing simultaneously—attributes, functions, and quality.

### Three Causes of Power-System Collapse

**Action**: Check the premise against all three hazards and apply the stated fix to any match.

| Cause | Solution |
|------|------|
| No progression line | Use a classic realm system as the progression framework |
| Flawed special advantage | Give progression multiple dimensions instead of relying on one |
| Social environment is too simple | Build real social relationships: taverns, masters and sects, friends, intelligence organizations |

## Advanced Special-Advantage Design

### Mismatched-System Design

**Action**: Prevent the system from functioning as intended and use the contrast between the system and protagonist to create drama.

| Mismatch | Example |
|----------|------|
| Time mismatch | The counterattack system arrives after the protagonist is already invincible; a kindergarten strategy system arrives in college |
| Spatial mismatch | The protagonist lives in a normal world but awakens an apocalypse system |
| Target mismatch | A system intended for the emperor attaches to the empress |

**Principle**: The mismatch must create a large gap, and its drama must match the target audience’s expectations.

### Subverting System-Fiction Formulas

- State the system’s “subversion” directly in the title as the main gimmick
- Make the synopsis explain the satisfaction of one system cycle
- Do not show only the gimmick of “subversion”; show what the protagonist does with it

### Common System Types

**Action**: Select the system type that fits the story’s needs.

| Type | Characteristics |
|------|------|
| Point-allocation system | Simple and intuitive but one-dimensional; suited to intensely oppressive worlds |
| Proficiency system | Supports emotional extension and broad applicability; its underlying mechanism allows variations |
| Card-draw system | Familiar to readers but packaged with freshness |
| Store / exchange system | Resource-acquisition model suited to farming and management fiction |

### Special Considerations for Extreme-Martial-Arts Advantages

- The extreme-martial-arts world is defined by absolute class rigidity; conventional training cannot cross class lines
- Single-axis extreme point allocation is outdated. Combine elements instead: extreme martial arts + horror + exploration, or extreme martial arts + apocalypse + cautious survival

## Complete Framework for High-Concept Fiction

### Four Steps from Inspiration to Book

**Action**: Follow these four steps strictly and in order.

1. **Get the idea**: An early special advantage, image, or entry point
2. **Match a genre**: Determine which genre can absorb the idea
3. **Build the framework**: Center it on progression system, special advantage, and framework
4. **Design the plot**: Fill the framework with small repeating plot loops

### Special-Advantage Design: Condition–Feedback Model

**Action**: Choose a model from the table as the special advantage’s core mechanism.

| Variation | Design | Example |
|------|------|------|
| One condition, one response | Touch a corpse -> gain treasure | Most basic form |
| One condition, staged response | Touch corpses -> gain corpse-touch points -> advance and unlock functions | Retains the mechanism while enriching its presentation |
| Upgraded-condition response | Kill -> steal attributes -> combine attributes | Higher late-stage ceiling |

**Innovation techniques** (stack any):
- Several conditions produce one response
- One condition produces a probabilistic response
- A response generates new subabilities

### Framework Design for Main Plot and Transitions

**Action**: Framework = main plot + transitions between plot events. Answer the central question: What purpose does each plot serve?

Steps:
1. Define the protagonist’s initial state
2. Define every plot’s function and connect it forward
3. Let later plots permeate the preceding plot
4. Interweave nested small-plot loops according to the framework

Specific material can change flexibly while the core function remains constant.

### Small-Plot Loop Ideation

**Action**: Make every small plot follow four strict steps.

| Step | Content |
|----------|------|
| a1 | Establish the starting point: protagonist’s circumstances + goal |
| a2 | Introduce difficulty through a specific conflict |
| a3 | Special advantage / power takes effect |
| a4 | Release the payoff through astonishment, gain, or relationship breakthrough |

**Mini-loop for progression fiction**: Encounter dilemma -> improve through the advantage -> develop plot -> gain and daily life -> set up the major goal and expand the world

**Multilevel nesting**: Small loop -> medium loop (secondary goal) -> large loop (volume goal). Every small loop must set up anticipation for the large one.

### Three Keys to Extending High-Concept Fiction

1. Vary through repetition: Use different angles and conflicts around the same core selling point
2. Expand the world: Gradually unfold new maps, factions, and premise elements
3. Match the core selling point to the market: Cover enough reader needs

### Interwoven Multi-Formula Loops

**Action**: Choose one loop pattern from the table.

| Pattern | Effect |
|------|------|
| Multi-angle loop | Find several angles on the core selling point and write 1–2 volumes for each |
| Premise-expansion loop | Expand several formulas from the high-concept premise; simpler than the first method |
| No core expansion (counterexample) | Repeat one hook with different targets—continually humiliating new villains or collecting new followers—and readers tire by 200,000 Chinese characters because nothing genuinely changes; do not do this |
| High-emotion event loop (counterexample) | Depend on escalating tragedy or abuse—the protagonist suffers more and villains worsen each time—until the emotional threshold becomes impossible to satisfy |

## Genre Boundaries

### Execution Rules

- Every genre has explicit boundaries of reader expectation; readers reject material beyond them
- Choosing the wrong genre direction means even fluent prose cannot fulfill target-reader expectations
- Boundaries support accurate aim—perfecting what lies inside them creates a hit

### Determining Genre Boundaries

**Action**: Follow these steps.

- Examine high-quality to ten-thousand-subscription books in the genre; their shared elements define the boundary
- “Innovation” beyond the boundary is likely a reader turnoff
- When context or genre assets are insufficient, do not cross the boundary. Deliver the core expectations first, then add minor innovation

### Relationship Between Genre Boundaries and Special Advantages

- The special advantage must support the genre boundary
- Its core selling-point loop cannot drift from the genre
- Standard: Whatever brought readers in must continue to be delivered

## Rankings Scans and Book Deconstruction

### Ranking-Scan Principles

**Action**: Review different lists by platform.

- On Fanqie, review the reading and new-book charts; on Qidian, review Sanjiang recommendations and other featured lists
- For works on the Jinjiang “clip,” examine the trending elements that placed them there
- Gold lists contain mature works and are useful for extracting structural standards
- During a market scan, prioritize non-headliner books from the same platform and genre to obtain more reusable structural samples

### Correct Book-Deconstruction Approach

**Action**: Define the target dimension before deconstructing; do not read generally.

- Do not judge comparable value through personal taste; ask only whether the book provides reusable structural, emotional, or pacing modules
- Deconstruct with a specific question: How does conflict create emotional push-pull? Find and analyze ten conflict sequences
- Prioritize mid-tier samples; exclude headliners whose powerful brand, fan base, or other advantages cannot be reproduced
- Deconstruct only one dimension at a time: characterization, pace, contrast, suspense, and so on

### Extracting Material from Deconstruction

- During rankings scans, extract functional positions: trending elements, conflict structures, emotional chains, pacing arrangements
- Label notes by specific dimension rather than vague reading impressions
- Targeted deconstruction is more valuable than general reading
- Never deconstruct outside the genre context

## Comparable-Title Selection Rules

### Core Principle

**Action**: Choose a market-validated book ranging from high quality to ten thousand subscriptions, with a clear formula and framework.

### Three Exclusions

**Action**: Exclude these three types; do not use them as comparables.

| Excluded Type | Reason |
|----------|------|
| Headliners with powerful brands or fan bases | Brand momentum and prose skill obscure structure; functional positions cannot be reused directly |
| Trend-chasing books in a newly popular genre | The hit has already absorbed the traffic; a crude imitation will fail |
| Strong books with highly individual style | Their distinctive world and style cannot be copied |

### Complete Process

**Action**: Execute in this order.

```
检索同题材TOP 20作品的核心卖点与读者评论，提取高频剧情模式
  -> 确定题材内有哪些方向 -> 确定自己要写的方向
  -> 选5-10本参考书（读2-3遍到基本记下）
  -> 从参考书里选1本对标书
```

| Direction of Inquiry | Question |
|----------|------|
| Enjoyable books | Which books are best? Do reader comments match your view? |
| Shared direction | How are the best books broadly written? What similarities do they share? |
| Weak books | Root cause of weakness: Are you outside the audience, or is the writing poor? |

## Pacing Differences and Core Frameworks: Derivative vs. Original Fiction

### Essential Pacing Difference

- Derivative fiction needs no setup; it inherits anticipation and satisfaction immediately
- At the same length, derivative fiction feels more satisfying because its setup is faster

### Solving Pacing Problems in Original Fiction

**Action**: When writing original fiction, progress through this rhythm.

- Sacrifice some early satisfaction—a small payoff is enough—and repeat the core formula quickly
- After retaining readers, add detailed setup
- Pacing progression: one plot every 10,000 Chinese characters ×3 -> one every 20,000 ×2 -> one every 30,000 ×2 -> 80,000 ×N

### Level-One vs. Level-Two Structure

**Action**: Choose according to platform characteristics.

| Structure | Characteristics | Subscription Pattern |
|------|------|----------|
| Level one (episodic) | Evenly distributed payoffs with a small daily climax | Stable continued reading |
| Level two (setup -> reversal -> major climax) | Quiet period after the major climax | Fluctuating subscriptions and stepwise attrition |

### Verbosity Self-Check

**Action**: Compare against every item; if any matches, cut the draft.

- Never overexplain what one sentence can express accurately
- Minimize plot unrelated to the main line
- Reduce adverb frequency
- Repeatedly describing one thing makes the chapter lose focus

### Derivative-Fiction Essentials

- Use an appealing title and enter through the most-discussed plot
- Compress subplot characters: When the title targets one classic character, supporting characters should occupy no more than two chapters
- Match the source world’s naming: Use official names/translations for source characters rather than inventing them. Name new characters according to the culture and translation style of the corresponding region; do not mix language families within one region or use modernized or politicized names that contradict the premise

## Urban High-Martial-Arts Plot Templates

### General Goal Pool

**Action**: Select a combination of goals from the table. Every goal must connect to money.

| Goal Type | Options |
|----------|----------|
| Material | Move to a new home, obtain necessary resources, earn more money |
| Education | Enter college, enter a military academy, pass various examinations |
| Career development | Join the martial-arts hall, public-security bureau, or military |
| Family | Treat mother, save father, heal self, help relatives |
| Romance | Gain affection from a childhood friend or a school beauty who appears unexpectedly |
| Motivation | Look daily at a portrait of the world’s foremost prodigy for inspiration |

**Core principle**: Connect every goal to money, repeatedly. Without money, movement is impossible; with money, the world can be conquered.

### Available Plot Events by Setting

**Action**: Choose an event according to the current setting.

| Setting | Available Events |
|------|----------|
| School | Enter the genius class, earn rewards, compete virtually, monthly exam, fight the school bully, multi-school exam, national entrance exam |
| Martial-arts school | Win the master’s appreciation, inherit martial arts, fight a senior student, compete in city/provincial/national leagues |
| Police station | Help fight robbers, demons, evil instances, or a riot boss |
| Competition | Contracts with a martial-arts school / academy / martial-arts hall / military / national-security bureau / virtual network / celebrity event |

### Map-Change Formula

**Action**: When a map is exhausted, change it using this formula.

High school -> university; martial-arts school -> world’s premier martial-arts tournament; regional hall -> central hall; Blue Star -> other star systems. Repeat.

Rocket-jump method: Fight a university instructor -> president -> conglomerate -> America analogue -> middle boss -> major boss -> evil god.

## Genre-Specific Approaches and Identity-Driven Behavior

### Contract–Release–Suppress–Rise Pacing

**Action**: Confirm contraction, release, suppression, and rise before writing any chapter.

- Fiction requires contraction, release, suppression, and rise
- Handling the second chapter after a climax reveals the writer’s skill
- Before any climactic plot, ask whether the protagonist’s current level qualifies

### Identity-Behavior Boundaries

**Action**: Once the protagonist’s identity is set, constrain behavior strictly to it.

- A given identity performs actions appropriate to that identity
- Acting above one’s level = structural damage that breaks identification
- Overreaching turns plot into disconnected jumps: many climaxes without a continuous line

### Different Approaches by Genre

**Action**: Match the method to the genre.

| Genre | Writing Essentials |
|------|----------|
| Low-status Western fantasy | Write environment, not conflict; reversals and push-pull are unnecessary, while fluency is paramount |
| Eastern fantasy | Avoid extra characters; show only the protagonist in Chapter 1 and advance through monologue and thought |
| Conflict-based opening | Requires continual room for push-pull; the pace accelerates and easily collapses |
| Environment-based opening | Advances slowly with dense information and a smooth reading experience; easier to sustain at length |

### The Trap of a High-Emotion Opening

**Warning**: A high-emotion opening requires enough capacity for later escalation.

- Do not use one unless the volume outline can provide higher costs, stronger opponents, or deeper emotional reversals.
- After a high-emotion opening, every major node must escalate at least one dimension: cost, scope, truth, or relationship rupture.

### Genre-Element Synthesis

**Action**: Extract an element from Genre A and one from Genre B, then combine them into a new idea -> create a new book. Re-skinning method: Change the background and apply the idea to another genre.

## Romance-Arc Distillation Strategy

> Related: The authoritative overall romance framework—affection system / four stages / male- and female-audience differences—is “Affection System” in [character-relations.md](character-relations.md). This section covers only choosing between “two core-hook supports.”

### Two Core-Hook Supports for Romance

**Action**: Choose one pattern as the romance arc’s core.

1. **A specific dramatic romantic process**, such as forbidden love or regretful pursuit—different stages use different central emotional chains
2. **A specific dramatic characterization, pairing, or relationship**—the book’s overall experience comes mainly from the pair’s interaction pattern

### Iron Rule: Preserve the Interaction Pattern

**Action**: Once the leads’ interaction pattern is established, sustain it through the end. Changing it changes the central experience readers follow the book to receive.

### Career Arc Serves Romance

**Action**: When romance is primary, every career-arc event must serve it.

- Career functions: Cause the meeting / change the relationship / introduce a romantic rival or test from elders
- Showing off is allowed, but it must lead into romance content

### Harem-Character Design Principles

- Female leads should share visual similarities—if one is a petite archetype, make them all petite; if one is a mature archetype, make them all mature
- If recent samples on the target platform show that a “male best friend” clearly weakens appeal, replace that position with a relationship-generating character such as a bickering childhood-friend heroine

## Deepening Characterization vs. Deepening Story

### Two Paths

**Action**: Choose according to project complexity, available material, and target emotion.

| Path | Characteristics |
|------|------|
| Deepen story | Develop complex conspiracies, layered deduction, and battles of wits—high ceiling, high difficulty |
| Deepen characterization | Find drama in relationships and interactions—suited to projects with a clear main plot that need sustained freshness |

Core of deepening characterization: Create “fun” through interaction inside a simple, familiar story framework. First list the relationships, different desires, and interaction patterns among several characters, then map those patterns to repeatable plot points.

## Three-Step Plot Adaptation

### Core Principle: Strong Plot Emerges Through Adaptation

**Action**: Follow three strict steps.

1. **Find the target through conflict**: Define the protagonist’s current conflict -> search the “content library” for a similar plot -> locate the source work
2. **Side-by-side method**: Break the source work into a detailed outline and list its sequences vertically on the left -> place your book’s circumstances on the right -> adapt sequence by sequence
3. **Adjust and optimize**: Once the adapted story differs from the source -> validate pace, emotion, suspense, and motivation one by one

**Make it different and it becomes original**. The books have different foundations—world, relationships, and special-advantage circumstances—so literal copying is impossible.

## Working Backward from the 30,000-Character Turning Point and Writing Later Stages

### Reverse-Engineering the 30,000-Character Turning Point

**Action**: Work backward in this order.

- Define the turning point—the publication climax scene
- Reverse-engineer the opening plot from that point -> derive it step by exact step
- Within the first 30,000 Chinese characters, do not write a single word of showing off or humiliation unrelated to the turning point
- Design the central villain around that point

### Two Principles for Middle and Late Stages

**Principle 1**: Do almost nothing -> advance the main plot once a year
- Avoid changing the female lead’s opinion whenever possible; if possible, find a pretext to return it to the prior state
- Advance the main plot only occasionally -> like *Detective Conan*: routine cases + occasional hidden-track progress
- Preserve the basic elements relentlessly through 800,000 Chinese characters before disrupting them -> the book will likely become a major hit

**Principle 2**: Focus on tomorrow
- Build the plot around the immediate event—the father-in-law is returning, or the matriarch’s birthday approaches
- Do not scatter tracks from the beginning

## Faction Plotting and Motivation Development

### Four Basic Faction-Plot Patterns

**Action**: Choose the pattern suited to the current plot.

1. Protagonist -> enemy: Most common; the enemy troubles the protagonist directly
2. Ally -> enemy -> motivation shifts -> protagonist -> enemy: Ally is targeted -> protagonist steps forward
3. Protagonist -> Enemy A -> motivation expands -> protagonist -> Enemies B/C/D: Defeat the junior and seniors arrive
4. Protagonist -> ally: Misunderstanding / ideological difference / proving ability -> varies the plot + enriches characterization

### Critical Role of Third-Party Factions

They are not merely spectators who react in astonishment. More importantly, they “complete the logic” by testing whether the villain behaves intelligently and whether a powerful ally helps only because of protagonist privilege.

### Core of Strengthening Motivation

- Emotion accelerates motivation -> stronger emotion -> deeper identification between reader and character
- Redirecting hatred requires intense + logical motivation
- Anchor motivation in characterization

### Layered Setup (Motivation Example)

**Action**: Build motivation progressively through this pattern.

Escalation:
1. Transmigrator discovers the original body was poisoned -> revenge motivation
2. Original memories create deep attachment to the family
3. Family’s worry has not faded -> emotional setup
4. A nourishing dinner demonstrates family love
5. Poor parents work day and night -> family hardship
6. Debt incurred to pay for medicine -> economic pressure
7. Younger sister considers yielding to a rich delinquent to help the family -> ultimate emotional eruption

**Rule**: Do not suppress emotion continuously -> wish-fulfillment emotion moves in waves -> when suppression falls too low, introduce the special advantage to lift it.

### Strong Protagonist Side (Farming / Lordship / Sect-Building Fiction)

Weak protagonist side = a supporting character shows off independently, unrelated to the protagonist = readers are dissatisfied

Strong protagonist side = a subject / disciple / student shows off = the protagonist shows off = expanded payoffs

## Faction-Hand Method—Designing the Main Plot with Card-Game Logic

### Core Concept

Framework = the proportions and arrangement of main plot + subplots + daily life.

| Type | Definition |
|------|------|
| Main plot | The process that advances the story until its ultimate expectation is fulfilled |
| Subplot | A task that gains a supporting item or ability |
| Daily life | Warm interaction with characters |

### Applying the Faction-Hand Method

**Action**: Have different factions play in turns as in a card game.

- From the protagonist’s perspective, devise a response using techniques / treasures / knowledge
- From the enemy and audience perspectives, play cards and discuss
- Core: Order each faction’s characters by power -> advance level by level -> protagonist acts last and overwhelms

### Three Versions

**Action**: Choose according to project complexity and available context.

| Version | Structure |
|------|------|
| Basic | Characters with different positions hold different attitudes toward one event -> add suppression followed by elevation |
| Intermediate | Classic: audience -> Supporting Character A -> Supporting Character B -> Enemy C -> protagonist overwhelms -> major boss appears |
| Advanced | Protagonist does not enter; teaches a subordinate essential knowledge -> enemy reaches them after enormous difficulty -> suffers complete defeat |

### Universal Across Types

Progression fiction = techniques / treasures replace knowledge / technology as cards -> combat traits replace dialogue -> taking the stage replaces holding a meeting. The same plot-design principles apply to progression and non-progression fiction alike.

## Combining Three Books into a New Story

### Procedure

**Action**: Execute strictly in order.

1. Select three comparable books on the same platform, in the same genre and type, with recent data or comments that can be verified.
2. Extract a 300–500-Chinese-character synopsis, core hook, selling-point structure, and reader-comment keywords from each.
3. Deconstruct in three layers: (1) synopsis distillation—core hook and selling-point structure; (2) narrative-technique analysis—pacing and emotional triggers; (3) reader-appeal attribution—frequent positive terms in comments.
4. Reuse only functional positions during synthesis: core hook, pace, emotional trigger, and relationships; do not reuse specific sequences.
5. After producing the new story core, validate it with a 200-Chinese-character summary before outlining.

### Validation

**Action**: Summarize the intended story core in 200 Chinese characters, then check whether the central conflict is clear, emotional hook is effective, and special advantage is sufficiently demonstrated. At least two of three must pass; otherwise, the story core is unclear.

## Quality-Control Checklist

**How to use it**: After writing in a special genre, check every item. Return to the corresponding section to correct any failure.

### Special Advantage and Power

- [ ] Is the special advantage divided into several elements—interface / no regression / repeated improvement—instead of one dimension?
- [ ] Does it retain multidimensional late-stage growth through attributes + functions + quality, rather than only quality?
- [ ] Is a progression line established through realms or an equivalent framework?
- [ ] Does the social environment include enough relationships, rather than only protagonist + enemies?

### Genre and Boundaries

- [ ] Have genre boundaries been confirmed through common elements among high-quality to ten-thousand-subscription books?
- [ ] Does the special advantage’s core selling-point loop remain inside those boundaries?
- [ ] Does the story continue delivering what readers came for?

### Framework and Pace

- [ ] Is the purpose of every plot clear—main plot / transition / small loop?
- [ ] Does each small loop strictly follow setup -> difficulty -> special advantage activates -> payoff release?
- [ ] Does the small loop set up anticipation for the large loop?
- [ ] Does derivative fiction use level-one episodic structure, and does original fiction follow progressive pacing?

### Factions and Motivation

- [ ] Is the faction-conflict pattern clear and one of the four basic modes?
- [ ] Does the third-party faction complete the logic rather than merely watch in astonishment?
- [ ] Is motivation anchored in characterization and established layer by layer?
- [ ] Does emotion advance in waves rather than remaining oppressive or satisfying throughout?

### Romance Arc (If Applicable)

- [ ] Is the romance’s core hook clearly either “process-driven” or “character-interaction-driven”?
- [ ] Does the leads’ interaction pattern remain consistent throughout?
- [ ] Does every career-arc event serve the romance arc?

### Market and Adaptation

- [ ] Are comparable titles reusable samples from the same platform, genre, and type, excluding powerful brands, crude trend-chasers, and strongly individual works?
- [ ] Does each deconstruction isolate one dimension—characterization / pace / contrast / suspense?
- [ ] Does the adapted plot differ fundamentally from the source in world, characters, and special advantage?

### 30,000-Character Turning Point (If Applicable)

- [ ] Is the publication climax scene defined and the opening reverse-engineered from it?
- [ ] Is there any unrelated showing off or humiliation in the first 30,000 Chinese characters? If so, delete it.
- [ ] Is the central villain designed around the turning point?
