## Conflict Design Methods

### Four-Stage Conflict Escalation

Build layers of conflict in this order: person vs. self -> person vs. nature -> person vs. person -> person vs. world.

### Build the World on a Foundational Conflict

Begin worldbuilding with the deepest, most irreconcilable conflict. Make sure the core hook never drifts away from it, or mid-book subscriptions will decline.

### Three Sources of Motivation

| Source | Execution |
|------|---------|
| World background | Make the environment force the protagonist to grow stronger (for example, in a demon-plagued age, anyone without strength cannot protect themselves) |
| Special advantage | Use its mechanics to create an incentive (for example, killing demons grants power) |
| Relationships | Use what happens to friends and family as an emotional driver (for example, bullying or murder -> revenge or rescue) |

### Transitioning Between Motivations

- As soon as one crisis ends, use a supporting character or villain to emphasize that “survival demands greater strength,” naturally transitioning into the next stage.
- Life-or-death crises do not suit every genre—adjust the intensity of the hardship to the genre’s boundaries.
- Resolving one crisis must plant the seed of the next.

### Categories of Conflict Sources

Choose sources of conflict according to the genre:

| Source | Best For |
|------|----------|
| Resources / interests | Universal |
| Factions / races | Fantasy, Eastern fantasy |
| Paths to supernatural power | Occult mystery |
| Faith / religion | Western fantasy, historical fiction |
| Church–state struggle | Medieval settings, political intrigue |
| Ideology / values | Every genre |

## Structural Methods

### Working Backward from the Climax

Reverse-engineer the main plot in this order:

1. First, define the ending in one sentence.
2. Work backward through goals at every level (richest person in the world <-- state <-- nation <-- province <-- city <-- county <-- town <-- village <-- family).
3. Break the major main plot into mid-level main plots, then break those into small main plots, refining continuously.
4. After a small main plot is completed, the mid-level main plot becomes the new small main plot. Repeat the cycle.

### Main Plot = Conflict-Driven

The main story is the process of resolving conflict. Break a major conflict into smaller conflicts to form a story line. Every stage must contain one core conflict that cannot yet be resolved.

### Subplots = Means of Completing the Main Plot

Organize subplots with this logic: make money (main plot) -> how to make it (subplot) -> what to use to make it (confirm the special advantage). Every subplot must eventually converge with the main plot.

### Dual-Track Structure

#### Visible and Hidden Tracks

- **Visible track**: The protagonist’s track—the actions and growth readers see directly.
- **Hidden track**: The villain’s track or a hidden-element track, used to connect events, lay groundwork, and nest later plotlines.
- The hidden track must eventually intersect with the visible track to create the volume’s climax.

#### Four-Quadrant Structure

| | Visible Track | Hidden Track |
|--|------|------|
| **Main plot** | Protagonist’s power growth + advancement of the central plot | Villain’s covert actions / hidden-information track |
| **Subplot** | Resources, connections, and status | Supporting-character hidden track |

**The most efficient structure**: The visible track contains a main plot plus a subplot (“two carrying one”), while the hidden track contains only the main plot.

At the climax, merge the hidden and visible tracks; merge the subplot into the main plot or set it aside temporarily.

### Interwoven A/B Method for Progression Fiction

| Track | Definition | Content |
|------|------|------|
| Track A (progression) | Combat-power growth | Assign points, learn skills, improve equipment |
| Track B (plot) | Contradictions and confrontations | Introduce conflict -> become entangled -> confrontation erupts -> resolve confrontation -> reap rewards |

Interweaving rhythm:
```
变强 -> 拉出矛盾 -> 变强 -> 卷入矛盾 -> 变强 -> 引发冲突 -> 变强 -> 解决冲突 -> 收获 -> 变强 -> 拉出矛盾...
```

**Core principle**: Maintain a contest in which the protagonist has a slight edge. Let the protagonist win each small contest, culminating in a major victory.

Ways to enrich reader identification:
1. Enrich Track A by defining resources, connections, and equipment that can be acquired.
2. Enrich Track B by adding worldbuilding, environment, emotion, and character interaction, and by giving villains and supporting characters recognizable labels.

## Confrontation Design

### Extend the Plot with Thresholds

Use thresholds to divide the main plot into stage-level plotlines, each with a clear driving force:

| Threshold Type | Execution |
|----------|---------|
| System threshold | The first upgrade is free, the second requires resources, and later upgrades split into normal and premium tiers |
| Goal threshold | Admission to an elite academy requires a vitality score, confirmed kills, and a competition ranking; complete them one by one |
| Collection threshold | Advancing to the next realm requires multiple items; find them one by one |
| Consumption threshold | When resources become too abundant, raise the threshold to consume them |

### Reverse-Engineer Plot with Three Driving Forces

| Driving Force | Execution |
|--------|---------|
| Drama | Design unexpected gains and fortunate accidents |
| Conflict | Design unavoidable confrontations or disasters |
| Desire / fear | Use what the protagonist wants to gain or fears losing |

**Procedure**: First determine the protagonist’s stage-level growth (special-advantage upgrade / martial growth / love-interest affinity / treasure / influential connections / money / status), then try reverse-designing a plot for each gain using all three driving forces.

Advantage: You will never run out of material, and the story will continually feel fresh.

### Essentials of Confrontation Design

#### Core Standards

- Conflict must escalate: words -> action -> fierce confrontation -> decisive outcome.
- Conflict must have a clear result.
- At its core, conflict means “someone is preventing the protagonist from getting what they want.”

#### The Difference Between Contradiction and Confrontation

- A “contradiction” is a level-one structure operating across the entire book or volume; a “confrontation” is a level-two structure operating within a specific scene.
- Contradictions determine the direction of the main plot; confrontations are their concrete expression.

#### The Act-One Trap

While resolving the first confrontation, the protagonist plants the cause of the next one. Its function is to connect the story naturally.

#### The Windfall Technique

A windfall is a universal technique: it can serve as foreshadowing, groundwork, or a future plot hook, while also delivering an immediate payoff.

Classic pattern: The boss drops three items—1. something the protagonist can use immediately, 2. something to give away and build a relationship, and 3. something currently unusable but obviously powerful.

### Eight Confrontation Methods for Redemption Fiction

| Method | Execution |
|------|---------|
| Conflict over the redemption target | Redemption comes from the other person’s sacrifice; the person who caused the trauma is their close relative |
| Conflict over the act of redemption | Redemption depends on maintaining a lie; completing self-redemption requires hurting the other person |
| Triangular relationship | The redemption causes a third party to need redemption |
| Redemption countdown | It must be completed before a specific event, or the person will fall into the abyss |
| Escalating redemption cost | The required sacrifice grows continuously |
| Scarce redemption resource | There is only enough to save one person |
| Opposing positions | They disagree but need each other’s help |
| Personality contrast | Optimist vs. pessimist, cold-blooded vs. compassionate |

## Opposition Design

### Suppress Circumstances, Not the Individual

The villain does not target the protagonist personally. Instead, the villain’s plan targets a region, class, or group and objectively traps the protagonist in hardship.

Procedure:
1. Give the villain an independent objective (such as suppressing cultivators in a certain region).
2. Put the protagonist inside the oppressed environment.
3. After the protagonist overthrows the villain, the people at the bottom remain numb.
4. Those people may exploit the protagonist’s goodwill for personal gain -> new conflict.

Advantage: The conflict has a logical foundation and can be sustained.

### Villain POV and Information-Gap Technique

#### Function

Switch to the villain’s conspiracy to create an information gap in which readers know something the protagonist does not. This deepens the villain, builds anticipation, and makes readers eager to see the villain humiliated.

#### Execution

- Do not make the villain speak in riddles—state the plan openly.
- Information gap = let readers learn part of the information early to create anticipation.

See Dual-Track Structure above for hidden-track rules.

### Designing Protagonist Agency

Design the protagonist’s actions across these three dimensions:

| Dimension | Meaning | Example |
|------|------|------|
| Do what others dare not do | Defy authority, challenge the powerful | Kill a superior |
| Do what others cannot do | Escape certain death, exceed all limits | Survive an inescapable situation |
| Do what others never imagined could be done | Turn accidents to advantage, use an indirect solution | Use a grilled-sausage manual to complete a collection |

Drama is how agency is displayed; characterization is why the action occurs. Do not break characterization merely to create a surprise.

## Romance-Arc Design

### Coordinating Career and Romance Arcs

First ask what readers attracted by the title and synopsis came to see.

| Mode | Design Focus | What Readers Want |
|------|---------|---------|
| Career-first | Demonstrate and upgrade the special advantage; the love interest is a reward | The protagonist grows stronger |
| Romance-first | Changes in the relationship; design plot events around the other person’s characterization | Interaction between the pairing |

### Four Stages of a Romance Story

Advance the romance in this order:

| Stage | Core Content | Key Execution |
|------|----------|---------|
| Chance encounter | First meeting and impression | Create tension through contrasting judgments |
| Romantic comedy | Forced or accidental repeated contact | The testing stage is central and occupies 30–50% of the plot |
| Love divided by mountains and seas | External pressure, an identity revelation, or a misunderstanding separates them | Keep the intensity high; personality changes must grow from established characterization |
| Finale | Overcome the greatest obstacle | Introduce no new conflicts; focus on romantic rewards |

#### Writing the Testing Stage

The testing stage is the core of the romance arc: the two repeatedly test and pull at each other without confirming the other’s feelings. Every test should support both a “sweet” and a “bittersweet” reading.

#### Counterbalancing Character Changes

After the romance climax, the relationship advances: **both people change**, and their previous dynamic is **reversed** after those changes. Each change must modify part of an existing characterization, not invent a new one from nowhere.

## Special Advantages and Identity

### Designing the Opening and Entry Point (Dual Identities, Dual Special Advantages)

| Element | Design Requirement |
|------|---------|
| Explicit identity (social identity) | The visible label = occupation + status. It must keep changing |
| Hidden identity (origin) | A lost prince living among commoners, a transmigrator, and so on. Connect it to the book’s central conflict |
| Explicit special advantage | A system, memories of rebirth, and so on. It must be a collection of abilities that continually reveals something new |
| Hidden special advantage = protagonist’s personality | What makes the protagonist different is itself an advantage. It provides payoffs in the middle and late stages |

**Four-part unification principle**: The social identity, origin, special advantage, and personality must be highly unified.

### Special-Advantage Design Essentials

#### Five Qualification Questions

Check each question when designing the special advantage:

1. Does it distinguish the protagonist? Can it continually help overcome difficulties?
2. Is it tightly connected to the world and premise while creating a meaningful contrast?
3. Could it overshadow the protagonist? Can that be prevented?
4. When the protagonist’s resources increase a hundredfold or a thousandfold, can it still address the central conflict?
5. Can resolving conflict through the advantage also express the story’s ideas and theme?

#### Fragmentation

Break a complex special advantage into smaller capabilities and weave them into the plot as fragments. The incomplete collection creates long-term anticipation; acquiring each fragment must resolve at least one conflict.

## Loops and Payoffs

### Layered Payoff Design and Loop Writing

#### Nested Loop Design

Core creative idea -> identify the core selling point -> define the main plot -> derive the special advantage to support the main plot.

#### Parallel Plotting

While laying groundwork for Plot A, intersperse groundwork for Plot B; while laying groundwork for B, intersperse C. Keep setup and payoffs alternating without interruption.

#### Layered Payoffs

Stack payoffs in this order:

1. Spectators at the scene are astonished
2. Spectators elsewhere are astonished
3. Experts recognize the technique and are astonished
4. A supporting character’s information gap closes, astonishing them again

Payoff = protagonist shows off + supporting characters’ perceptions change. Focus on how those characters change before and after.

### Three Core-Hook Types

| Type | Operation | Best For |
|------|----------|------|
| Repeatable | Repeats within every level-one structure | Progression fiction, system fiction, entertainment fiction built on copied works |
| Nonrepeatable | Runs through the entire text but erupts only once at the greatest climax | Winning back an estranged partner, identity revelation, forbidden love |
| Long-term setup | Runs throughout as anticipation points | Mystery, revenge, puzzle solving |

Operating rhythm: The hook must run once or receive its first setup within the first level-one structure. If several consecutive level-one structures do not run it, readers will abandon the book.

Dual-track ideation: Create two tracks—one repeats the core hook, and the other does not. Alternate between them.

### Design the Loop Core by Genre

Choose the loop core according to the genre and keep its sustaining condition intact:

| Genre | Loop Core | Sustaining Condition |
|------|---------|----------|
| Skill-grinding / low-status opening | Map (training grounds / local tyrant / saboteur) | The map remains intact |
| Immortality | Social change | Society keeps changing |
| Infinite-game fiction | Instances and reality | Neither the instances nor reality collapses |
| Road fiction | Interpersonal encounters | Characters remain consistent |
| Overpowered-protagonist fiction | Enemies | Enemies remain credible |
| Farming / daily check-in / stockpiling | Damage to the external environment | The outside world keeps deteriorating |
| High-concept fiction | Core selling-point loop | The core selling point does not drift |

**Warning**: Letting the loop drift from the core selling point destroys the story’s competitive differentiation.

## Motivation and Dilemmas

### “Give the Character a Dream” Motivation Method

| Concept | Trait | Example |
|------|------|------|
| Motivation | Driven by external forces, tends toward material needs | Is poor -> wants to buy a large house |
| Dream | Driven from within, seeks spiritual fulfillment | Wants to become a great writer |

Execution: In addition to external oppression or material incentives, give the character a “dream.” Combining both layers naturally makes the character vivid.

Character goals must fit characterization—a servant disciple dreaming of saving the sect is unconvincing, while the sect’s holy maiden doing so makes sense.

### Dilemma Loop Structure (Extreme-Martial-Arts Style)

```
困境（环境压迫）-> 行动（运行金手指）-> 转折（更大困境）-> 行动（更强实力突围）
```

Core: Keep increasing pressure on the protagonist, who must always take the initiative in solving problems. Combine this with concealing strength, emotional push and pull, showing off, and humiliating opponents.

Key point: Calibrate the oppression so readers believe the protagonist has hope of breaking through. Late-stage pressure must exceed early-stage pressure.

### Extrapolating Plot from the Premise

Core formula: **environment + character = plot**

Procedure:
1. Define the environment (time / location / circumstances).
2. Define the character (identity / relationships / motivation / weakness / dream / history).
3. Each time you add a premise element, role-play its logical consequences.
4. Select the combination that best serves the core emotion.

### Gimmick–Main Plot–Core Payoff Framework

#### Gimmick Types

| Type | Trait | Opening Approach |
|------|------|---------|
| Event gimmick | The title is the event | Enter the event immediately |
| Special-advantage gimmick | Distributed throughout the text, frequent early and less frequent later | First depict the protagonist -> dilemma -> goal -> use of the advantage -> modest result |
| Characterization gimmick | Characterization directly affects the plot | The characterization itself creates drama |

**Rule**: Event gimmicks and special-advantage gimmicks require different approaches. Writing an event with the special-advantage approach makes readers abandon the book.

#### Attaching the Gimmick to the Main Plot

As soon as the event ends, **immediately attach** the protagonist’s goal. You may also begin laying the goal’s groundwork during the event.

#### Core Payoff = A Payoff on the Main Plot

Showing off away from the main plot is a displaced payoff, not a core payoff.

#### Presence and Reaction Rule

Presence rule: The intensity of the protagonist’s response to provocation should be proportional to their established strength and experience. A powerful character should react casually instead of lashing out in rage. Design reaction patterns according to the character’s power level: high power → casually dismissive / kills with one finger; low power → endures while gathering strength. Designing a response to an insult:
- Reader turnoff: becomes furious, face flushed red
- Acceptable: smiles slightly—“He is nothing”
- Hysteria -> dissatisfaction; casually killing with one finger -> payoff

## Plot Organization

### Information-Delivery Sequence

| Type | Structure | Best For |
|------|------|------|
| Straightforward plot | Raise a question -> reveal the answer | Basic narration |
| Exploratory plot | Raise a question -> provide an honest clue -> reveal the answer | Setup sections |
| Surprise plot | Raise a question -> provide a false clue -> reveal the answer | Reversal sections |
| Surprise + reversal | Raise a question -> false clue 1 -> false clue 2 -> reveal the answer | Climactic sections |

Readers care about information only after it becomes a “question.” Every event must create at least one change in value and advance the main plot. An event without a value change is padding.

### Expand a Relationship Network from the Protagonist’s Daily Route

Define the protagonist’s routine activity route -> introduce new characters at routine points of contact -> each new character brings a relationship network -> new story material.

### Stepwise Progression and Buffer Zones

- A buffer zone is the distance between the protagonist and a supporting character created by interests, events, or feelings. Closing that distance creates a payoff.
- Divide goals into stages (like Qi Refining / Foundation Establishment / Golden Core). Both major and minor goals can be divided.
- Three modes of plot advancement: proactively handle trouble that blocks the goal / proactively pursue the goal and encounter trouble / trouble arrives at the door but ends up advancing the goal.

### Event-Driven Principle

- Main-text chapters must consist of events, and events must occupy at least half the content.
- Events create opportunities for value changes; without events, neither the protagonist nor the main plot changes.
- Dramatize the premise through events whenever possible instead of forcing it into narration.

### Extrapolating Conflict from the Premise

Priority:
1. **Interesting before useful**: First make sure the event has dramatic appeal.
2. **Extracted plot events already contain drama**: When deconstructing another book, directly use events that contain payoffs.
3. **When an event is not interesting enough, use setup to build anticipation**.

## Quality-Control Checklist

After completing conflict and structure design, check every item:

- [ ] Do conflicts progress through all four levels (self -> nature -> person -> world)?
- [ ] Is the foundational conflict tightly bound to the worldbuilding without drifting from the core hook?
- [ ] Does the protagonist have at least two of the three motivation sources (world background / special advantage / relationships)?
- [ ] Was the main plot divided into major, mid-level, and small plotlines by working backward from the climax?
- [ ] Does every confrontation keep escalating (words -> action -> fierce opposition -> decisive outcome), with a clear result?
- [ ] Does every stage contain an unresolved core conflict that drives readers onward?
- [ ] Do all subplots eventually converge with the main plot?
- [ ] Does the hidden track, if any, intersect with the visible track at the climax?
- [ ] Does the romance arc, if any, follow the four stages, with the testing stage occupying 30–50%?
- [ ] Does the special advantage pass all five qualification questions, and are its abilities fragmented into the plot?
- [ ] Are the explicit identity, hidden identity, explicit special advantage, and hidden special advantage unified?
- [ ] Does the core hook run once or receive its first setup within the first level-one structure?
- [ ] Does the loop core match the genre without drifting from the core selling point?
- [ ] Does every event create at least one value change and advance the main plot?
- [ ] Does the information-delivery sequence fit the scene type (basic / setup / reversal / climax)?
- [ ] Do motivations transition naturally, with each resolved crisis planting the next?
