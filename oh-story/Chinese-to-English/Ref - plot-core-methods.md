## Four-Step Brief-Outline Method

Keep the detailed-outline-to-main-text ratio between **1:2.5 and 1:3**.

Follow these four steps:

1. **Divide into segments** — Break the master outline at plot nodes
2. **Label purpose and effect** — Mark each segment without expanding its events
3. **Mark detailed/summary treatment** — State which segments to expand and which to pass over
4. **Enable quick location** — Let later drafting quickly identify the purpose and effect the segment must deliver

Remember: A detailed outline focuses only on purpose and effect, not expanded plot events.

## Reverse-Engineering the Climax and AB Rough Outline

### Core Idea

Work backward from the climax to identify the characters and events that require setup, then fill the outline by alternating A and B segments.

### AB Rough-Outline Method

| Marker | Meaning | Execution |
|------|------|------|
| A | Suppress emotion / setup / foreshadowing | Establish difficulties, a powerful opponent, and suspense |
| B | Raise emotion / suggestive edge / small gain | Minor reversal, small progress, quick reader satisfaction |

Process: Define the climax → reverse-engineer the required setup → arrange ABABAB → while drafting, focus only on the current AB segment.

Best for fast-paced plots with clearly defined climax nodes.

## Climax Formula

### Five-Step Formula

Execute in order: **charge → false victory → collapse → crosscut struggle → suspended ending**

1. **Charge**: Build on sacrifice + anxiety, turning the audience from “spectators” into “participants”
2. **False victory**: Offer hope, then shatter it (emotional gap = reversal impact)
3. **Collapse**: Detonate all foreshadowing at once + force the protagonist into solitary desperation after every helper is lost
4. **Crosscut struggle**: Switch between the confrontation track and desperation track; every cut adds one level of tension
5. **Suspended ending**: Preserve the momentum without immediately revealing the winner

Key execution: A false victory is a common climax technique, best for major reversals, intense oppression, or a large climax. Low-pressure chapters, pure-reward chapters, and slice-of-life or relationship-resolution chapters may omit it. Without a false victory, use another technique to create an emotional gap or deliver a clear payoff.

## Gimmick Categories and Opening Process

### Three Gimmick Types

| Gimmick Type | Characteristics | Writing Essentials |
|----------|------|----------|
| Event gimmick | Concentrated in the opening, about five chapters | Enter the event immediately; do not set up transmigration or the special advantage |
| Special-advantage gimmick | Distributed across the entire text, more frequent early and less frequent later | Establish the protagonist and dilemma before introducing the advantage |
| Characterization gimmick | Characterization directly shapes plot construction | Use only when the characterization itself can continually create drama |

Rule: Do not mix event-gimmick and special-advantage approaches.

### Two Standard Opening Processes

**Event opening**: Enter the event (five chapters) → attach the main plot → divide the goal → cycle through stage-level payoffs

**Main-plot opening**: Describe the protagonist’s current state → create identification → depict the social environment → establish the protagonist’s goal → divide the goal by setting thresholds → bind the special advantage → achieve the first improvement → create emotional push and pull 2–3 times → complete the goal → introduce the next goal

### Gimmick Traffic Strategies

| Strategy | Approach |
|------|------|
| Extended gimmick | Build around the opening gimmick and continue with similar gimmicks |
| Traffic-driving gimmick + conventional story | The opening gimmick only attracts readers; afterward, follow conventional genre content |

The opening gimmick’s function is to establish the promise behind the click and continued reading. Once achieved, it must connect to the main plot.

Before starting the book, ask whether the gimmick can generate substantial later material. If not, use the “traffic-driving gimmick + conventional story” strategy.

## Correct Definition of the Main Plot

**The main plot is not progression**. The main plot is one undertaking; progression is what the protagonist does to achieve it.

| Concept | Definition | Example |
|------|------|------|
| Goal (main plot) | One undertaking the protagonist must complete | *Battle Through the Heavens*: Go to the Misty Cloud Sect for revenge |
| Action | What the protagonist does to achieve the goal | Train hard and continually grow stronger |

Check whether the main plot has these characteristics:
- It is one undertaking, not a list of elements
- Once it is completed, either setup launches a second main plot or the book ends
- A misplaced anchor makes every later plot event drift

## Writer’s-Block Responses and Plot-Loop Design

### Core Formula

Genre + special advantage + protagonist identity = loop pattern. All three must be unified.

### Six Classic Loop Patterns

| Pattern | Loop Mechanism | Fuel |
|------|---------|---------|
| Case-chain loop | Case → solve mystery → partial truth → greater mystery → new case | Information gaps + deduction |
| Concealed-strength loop | Quietly develop → provocation → overpower → astonishment → continue developing | Reader–character information gap |
| Resource-accumulation loop | Resources → skills → power → new map → new resources | Upward spiral |
| Dramatic-reversal loop | Lose money → reversal earns more → invest more to lose it → earn again | Does not depend on numerical inflation |
| Organization-hub loop | Separate adventures → information converges → new plots emerge | Information exchange + multiple tracks |
| Road-movie loop | Travel → meet someone → travel again → meet someone else | Characterization strength |

### Four-Faction Map Framework

The starter village—the opening map—must contain four faction types that create a closed resource loop. This is the complete framework; later map changes may simplify it (see “Map Detail by Stage” below), but never lose the channel for monetization and resource circulation:

1. **School / martial-arts school** — Learn skills and improve power
2. **Merchants / apothecaries** — Sell gains and acquire resources
3. **Bandits / enemies** — Targets for demonstrating what was learned
4. **Government / governing body** — A higher route for advancement

### Status–Environment Synchronization Principle

As status rises, environmental danger must rise. If they fall out of sync, readers become bored.

### Three Map-Change Strategies

1. **Link old and new maps** (the new faction outranks the old)
2. **Bring people along** (move important characters to the new map)
3. **Set up the appeal early** (make readers actively anticipate going there)

### Handling Special Types

- **Genius progression**: Dramatically increase the number of levels so the numbers do not collapse within a few dozen chapters
- **Overpowered protagonist**: Shift the loop core to information gaps—instantly defeat each arrival while repeatedly refreshing perceptions

## Slice-of-Life Outline Framework

### Creative Path

Follow these steps:

1. Find an interesting premise, relationship, or background while reading
2. Define a career arc + romance arc around the inspiration
3. Enter at the fastest-paced, most emotionally charged node
4. Divide each stage into information gaps + relationships + emotion
5. Arrange events chronologically
6. Sketch the chapter outline before drafting

### Outline Extrapolation

Using “establish a landlord–tenant relationship” as an example:

1. Goal: Make the male and female leads landlord and tenant
2. Break down: The protagonist’s home needs a spare room near the high school
3. Extrapolate: A spare room = a well-off family → preferably purchased with a mortgage, creating pressure
4. Reversal rationale: The parents made a failed investment in the previous life → the protagonist reverses it in this life → buy a home in the school district

### Outline-Node Format

```
事件名称：
信息差：1. 主角知道什么/配角不知道什么 2. 读者视角 vs 角色视角
人际关系与情绪：1. 主角情绪 2. 女主/配角反应 3. 负面情绪提供者
```

### Key Principles

- The outline serves main-text generation; it is not a shackle
- Slice-of-life fiction should not use too many major events that sharply increase affection; link small events into slow growth
- Connect the career arc to the female lead and her family so daily life and career blend together

## Large-Plot Anticipation Method

### Top-Down Creative Logic

Execute in order:

1. **Define the core and purpose** — First determine the major payoff for this large plot
2. **Set a length target**
3. **Design stage-level plots** — Create several smaller plots around the payoff, each setting up the next
4. **Fill with a blend of techniques**

### Example: Performing “Blue and White Porcelain” on *Sing! China*

**Core payoff**: The protagonist performs “Blue and White Porcelain” onstage and astonishes everyone

Stage design:
1. Receive an invitation + hum “Farewell” in a park → astonish a judge (early hint)
2. Face provocation at rehearsal → create pressure
3. Write “Bubble” for G.E.M. the night before the show → add another display of ability
4. Live competition → equipment failure (more pressure) → perform “Blue and White Porcelain” → astonishment
5. Judge deducts points → tied score (reversal and suppression)
6. Singer performs the protagonist’s work → reveal that the protagonist is the creator (second-level astonishment)
7. Equipment failure explained → score reverses upward (doubled reversal)
8. Judge requests “Farewell” → sustain anticipation

Key point: Begin with the major payoff, then create stages for reaching it. Locally, the pace feels fast; globally, progress feels slow because the whole sequence tells only one story.

## Continuity Tracking and Pacing Management

### Heat States

| State | Definition |
|------|------|
| hot | Core element currently driving the conflict |
| warm | Recently active element |
| cold | Untouched beyond the safe interval and at risk of being forgotten |
| archived | Completed or deliberately closed element |

### Valid-Touch Test

A valid touch directly advances the thread, applies pressure, changes relationship state, creates a real consequence, or explains a plausible reason for dormancy.

Simply naming something, making an empty callback, or mentioning it randomly does not count.

### Review Thresholds

| Element Type | Touch Interval |
|----------|----------|
| Core character | 3–5 chapters |
| Major subplot | 4–6 chapters |
| Active foreshadowing | Two missed opportunities |
| Unstable relationship | Two appearances |

### Required Chapter Self-Check

1. What element is currently hot?
2. Has anything become cold that should be warm?
3. What can reasonably remain dormant?
4. Which returning thread could deepen the pressure?

### Failure Signals (Correct Immediately)

- Readers ask, “Whatever happened to that person?”
- An important clue suddenly appears only at the ending
- Cold setup abruptly becomes a hot payoff without warming up

### Pacing-Protection Rules for the Central Conflict

1. Chapters other than the finale generally do not resolve the book’s central conflict. When a stage-level central conflict ends, open the next expectation at the same time
2. The final roughly 200 Chinese characters should retain suspense, a decision, a discovery, an aftertaste, or a stage goal; low-pressure chapters do not require hard suspense
3. A local victory may bring a new cost, risk, or assignment; pure-reward and low-pressure resolution chapters may instead provide clear gains and future anticipation

### Cooldown Chapters After Events

| Event Type | Cooldown (Chapters) |
|----------|-----------|
| conflict_thrill (major confrontation / fight) | 2 |
| bond_deepening (deeper relationship) | 1 |
| faction_building (building a faction) | 2 |
| world_painting (expanding the world) | 3 |
| tension_escalation (increasing pressure) | 2 |

Rule: During its cooldown, an event type cannot serve as the main beat. conflict_thrill may run for no more than two consecutive chapters. Every five chapters must include bond_deepening or world_painting.

### Managing Transition Chapters

- Introduce the next goal before the current episodic story ends
- A transition chapter must maintain at least one active anticipation thread

### Carrying Anticipation Across a Map Change

| Method | Approach |
|----------|------|
| Revenge arc | Carry an unfinished objective across maps |
| Existing-relationship arc | Bring an established character into the new map |
| Information gap | One party believes something that is not true |
| Early setup | Before the transition, connect the protagonist with a character or legend from the new map |

### Four-Stage Evolution of the Special Advantage (Foundation → Development → Maturity → Transcendence)

| Stage | Execution |
|------|---------|
| Foundation | Clarify the core function and establish reader understanding |
| Development | Add new uses without changing the core function |
| Maturity | Integrate deeply with the worldbuilding and connect it to other systems |
| Transcendence | Expand the target from the individual to the world or heavenly order, supported by sufficient foreshadowing (check-in system: check in for items → everything allows check-in → check in on people or ley lines → checking in becomes a law of the world and an object of universal faith) |

Rule: The special advantage’s focus may shift, but only with sufficient foreshadowing. It may fade partially but cannot be discarded. The force of its presentation should increase at every stage.

### Conflict-Network Design

- Keep 2–3 conflict threads operating simultaneously
- Connect them through causality, competing interests, or information gaps
- Every resolved conflict must activate or deepen another

| Level | Range | Explanation |
|------|------|------|
| Chapter | 2–3 chapters | Small conflict serving the current unit |
| Volume | One volume | The volume’s central conflict, resolved at its end |
| Book | Entire book | Ultimate conflict, resolved in the finale |

### “Two Long, One Short” Anticipation Rule

- One short-term expectation: the current unit’s clear goal; there can be only one
- One or two long-term expectations: distant-goal preview / suspense / organization / character

### Methods for Sustaining Anticipation

1. Add detail to the “baseline expectation,” creating a new, concrete need gap
2. Alternate among several core hooks (showing-off Arc A + mystery Arc B + romance Arc C)
3. Design world-level “secrets” and “conspiracies”

### Managing Differentiation in Progression

| Dimension | Explanation |
|------|------|
| Ability differentiation | Every level grants a qualitatively new ability (Qi Refining permits sword flight → Foundation Establishment permits telekinetic attacks) |
| Treatment differentiation | Different levels receive different social treatment (Qi Refining serves as a menial disciple → Foundation Establishment receives a private residence) |
| Relationship-network differentiation | Different levels interact with different social tiers (Qi Refining meets only fellow disciples → Foundation Establishment earns an elder’s regard) |

If none of the three dimensions changes clearly after advancement, readers will not feel the satisfaction of progression.

### Nesting Episodic Stories

- Before the first story unit reaches its climax, introduce an anticipation thread for the second
- Before completing the current goal, plant a clue to the next one
- After completing the current goal, quickly introduce a reversal or disruption that creates new anticipation

### Long-Range Pacing Design

- One volume = one complete mid-level nested structure with its own setup, development, turn, and resolution
- Each volume opens with a 5–10-chapter identification period, develops through the middle, and ends with climax + resolution
- Alternate high information density (strong emotion, fast advancement) with low density (setup and accumulation); do not remain permanently high or low
- Every low-density chapter must plant at least one reason to want what follows

### Anticipation Management

Run three layers of anticipation simultaneously:
- Short-term: What happens next chapter?
- Mid-term: How will this plot unit conclude?
- Long-term: Can the protagonist ultimately achieve the goal?

## Plot Transitions and Connections

### Moving from One Plot Point to the Next

Core problem: The protagonist has grown stronger, but the next action is unclear. Solution: Introduce a new challenge or goal immediately after every improvement.

### Plot Nesting

- Large nest: The book’s main plot
- Medium nest: Each volume or stage’s intermediate goal
- Small nest: Each plot unit’s immediate goal
- Run all three layers simultaneously so readers always have something to follow

### Scene Transitions

- Skip transitional scenes when appropriate; do not drag them out
- A transition is not filler; delete it if it contains no information

### Emotional Connection

- The emotion from one scene must transition naturally into the next
- Do not jump abruptly from passionate intensity to flatness

### Information-Gap Connection

- Resolve an information gap from one scene in the next
- Let readers enter the next scene with a question, creating a natural and effective connection

## Set Thresholds—the Core Technique for Extending Plot

### Essence of a Threshold

A threshold should not be merely one enemy blocking the road. It should create a systematic set of conditions: To achieve the goal, the protagonist must satisfy a series of requirements.

### Specific Threshold Methods

| Threshold Type | Example |
|----------|------|
| Resource | A system upgrade requires 1,000 spirit stones, but the protagonist has none |
| Achievement | Admission to an elite academy requires a sufficient vitality score + independently killing an XX-level monster + placing in the top five |
| Multiple conditions | Divide one major goal into several stage-level goals |
| Dynamic | Raise the threshold when the protagonist’s resources exceed expectations |
| Collection | Advancing to the next realm requires several treasures |

### Rules

- Design thresholds around the core selling point; thresholds disconnected from the special advantage and high-concept premise create ineffective plot
- Introduce thresholds in batches, not all at once
- Establish the next threshold immediately after crossing one

### Loops Emerge from the Premise

- The core selling point is expressed through the “premise”; once the premise is defined, a feedback mechanism emerges naturally
- Every additional premise rule adds another layer of loop elements and more writable material
- Losing the premise while drafting = losing the selling point

## Scene-Change Techniques

- Skip any transition scene without information
- Leave suspense in one scene and answer it in the next
- When one scene ends with passion, open the next with its aftertaste
- When changing POV, cut away at a suspense point, not a quiet one
- Leave a “hook” on every track before switching away
- Readers care about different tracks to different degrees; the main plot must receive the largest share

### Deep Design for Map Changes

- New map = new environment + new characters + new rules + new goal + new conflict
- Before changing maps: Resolve the old map’s central conflict at least temporarily
- After changing maps: Establish fresh identification and anticipation quickly within the first five chapters

Avoid discarding every old character at once, dumping every new premise element together, or making the new map unrelated to the old. Preserve at least one continuous main-plot thread.

Upgrade the loop with every map change: greater scale, higher thresholds, and stronger opponents.

### Map Detail by Stage

- For a map change outside the starter village, simplify to three factions: training ground (martial-arts school / academy), local power (wealthy local / regional faction), and disruptor (bandits / marauders). This is a streamlined version of the “four-faction map framework,” but it must still preserve the monetization/resource-loop channel through merchants or apothecaries; do not leave only combat
- Expand the relationship network along the daily route: school attendance, returning equipment, and visiting the market can bridge into new story arcs

## Suspense and Foreshadowing Techniques

- Small-plot foreshadowing: Define the ending first, then work backward through clues to ensure a closed logical chain
- Full-book foreshadowing: Define key events during outlining, continually plant corresponding details in the book, and track long-term foreshadowing so it is not forgotten
- Cryptic withholding vs. foreshadowing: Cryptic withholding deliberately refuses to explain and easily frustrates readers. Foreshadowing integrates clues naturally and unobtrusively. Test: Delaying information for more than three chapters with no progress in between = cryptic withholding; delete it or reveal it sooner. The protagonist casually mentioning a fear of water, resolved by a drowning crisis later = foreshadowing
- Cerebral plot: Follow only the protagonist’s POV and omit the villain’s perspective to preserve suspense

## Information Clusters

- Information cluster = the core unit of information a plot section must convey
- Every cluster must be summarized by one sentence answering, “What is this passage about?”
- Clusters must advance logically
- Fast pace = dense clusters; slow pace = sparse clusters; padded chapter = zero clusters or clusters unrelated to the main plot
- Example: In one chapter, “the protagonist exposes a scam” is one information cluster, while “the villain’s background is also explained” is a second. If they are unrelated, the chapter is padding; cut the second or make it serve the first

## Self-Indulgence Test

### Three Self-Check Questions (All Must Be Answered Clearly)

1. Who am I writing this book for? Include at least the target reader’s age range, occupation, gender, usual platform, life circumstances, and common desires
2. What does my target audience want to see when reading web fiction?
3. Which parts of this book are things that audience wants?

Standard: If any one question cannot be answered well, the project is self-indulgent. Stop immediately and correct it.

### Corrections

- Analyze reader comments on comparable books and extract frequent positive terms
- Compare the traits of high- and low-engagement sections in comparable books
- Validate this book’s plot choices against the audience profile for comparable books

## Quality-Control Checklist

After completing a plot section or volume outline, check every item:

### Basic Completeness
- [ ] Is the main plot clearly “one undertaking,” rather than a list of elements or progression entries?
- [ ] Is the loop pattern unified with genre + special advantage + protagonist identity?
- [ ] Are all three layers of nesting (large / medium / small) active?

### Pacing and Anticipation
- [ ] Are all three layers of anticipation (short / medium / long) active?
- [ ] Do the final roughly 200 Chinese characters retain suspense, a decision, discovery, aftertaste, or stage goal?
- [ ] Does information density alternate between high and low instead of remaining constant?
- [ ] Are cooldown rules followed?

### Continuity
- [ ] Are hot/warm/cold states healthy, with no cold element that should be warm?
- [ ] Have core characters received a valid touch within 3–5 chapters and major subplots within 4–6?
- [ ] After changing maps or stages, does at least one main-plot thread continue across the transition?

### Climaxes and Transitions
- [ ] Does the climax need a false victory that gives hope before shattering it? If not, is there another emotional contrast or method of delivery?
- [ ] Does the victory need a cost, risk, or next assignment? If it is a pure-reward chapter, are the gains sufficiently clear?
- [ ] Were information-free parts removed from transition scenes?
- [ ] Does the scene change cut away at a suspense point?

### Pitfall Check
- [ ] Are thresholds designed around the core selling point rather than ineffective plot?
- [ ] Does the special advantage evolve through four stages without skipping or being discarded?
- [ ] Can all three self-indulgence questions be answered clearly?
- [ ] Can every information cluster be summarized in one sentence answering “What is this about?”
