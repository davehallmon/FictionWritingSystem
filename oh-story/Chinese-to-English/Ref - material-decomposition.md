## Short vs. Long Form: Core Differences

| Dimension | Long form | Short form |
|------|------|------|
| Length | Hundreds of thousands of Chinese characters and hundreds of chapters | 5,000–15,000 Chinese characters and 6–12 sections |
| Arc | Interwoven lines and multiple volumes | One arc and a compressed three-act structure |
| Characters | Ensemble and tiered system | Lean cast of 3–5 with concentrated functions |
| Worldbuilding | Complex settings and power systems | Primarily realistic with few special rules |
| Driver | Payoff loops and progression | Explosive beats and reversal impact |
| Reader attachment | Following serialization | Reading in one sitting |
| Analytical focus | Structural integrity and foreshadowing | Emotional design, techniques, and pace |

**Short fiction runs on resonance and explosive beats. Deconstruction identifies the story kernel, how it is prepared, and where it detonates.**

## Analytical Approach

### Core Principles

| Principle | Description |
|------|------|
| Story-kernel driven | Identify the one-sentence central hook first and organize all analysis around it. A changed kernel changes the whole direction |
| Reader viewpoint first | At every step ask what readers see, feel, and care about. Do not speculate about author intent; analyze experience actually produced by the text |
| Reusability | Every observation yields a transferable structure, functional position, or risk threshold. Pure appreciation does not pass |
| Explosive beat centered | Ask what produces emotional eruption and motivates sharing, then deconstruct its setup and release |
| Resonance drives spread | Prose quality alone does not determine reach. More layers of resonance increase shareability |

### Analytical Order

```
故事核 → 结构 → 人物 → 情感线 → 写作手法 → 共鸣+爆点性+话题性 → 综合评估
  │         │       │       │          │              │                  │
  │         │       │       │          │              │                  └─ 可借鉴结构
  │         │       │       │          │              └─ 为什么能火
  │         │       │       │          └─ 怎么写出来的
  │         │       │       └─ 读者感受到了什么
  │         │       └─ 谁在推动故事
  │         └─ 怎么布局的
  └─ 写的是什么（锚定一切分析的起点）
```

### Core Question at Each Stage

The objective is to answer questions, not fill forms mechanically.

| Stage | Core question | If unanswered |
|------|----------|-------------|
| Story kernel | What does this story sell in one sentence? | It has not been understood |
| Structure | How are opening, development, climax, and ending allocated? | Pace cannot be understood without layout |
| Characters | Who is protagonist, active, and passive? | The story's source of movement is unclear |
| Emotional arc | How are readers' emotions pulled step by step? | The core value of short fiction was missed |
| Techniques | What textual methods produce this experience? | Techniques cannot transfer unless reduced to reusable functions |
| Resonance + explosive beat | Why can it spread, and what resonance does it trigger? | Analysis has become literary appreciation |
| Overall assessment | What can be reused, under what conditions, and with what risks? | It cannot guide the next artifact |

### Constraints

1. **No subjective evaluation**: analyze mechanisms without saying “well written” or “poorly written.”
2. **Infer method from experience**: locate reader-emotion peaks first, then identify how the text creates them.
3. **Depth before breadth**: go deep on the kernel, explosive beat, and resonance; use optional dimensions as needed.
4. **Reusability**: every point includes conditions, transferable practice, and risk boundary.

## Five-Stage Deconstruction Pipeline

> **Numbering**: Phase 1—confirming the target and genre routing—is the top-level workflow in SKILL.md. This file defines pipeline Stages 2–6.

### Stage 2: Structural Analysis + Plot-Node Extraction

- Identify chapter/section delimiters such as `###01`, `第一章`, or `01`.
- Extract titles and record length of each section.
- Extract the **story kernel** in three layers:
  - **Premise**: precondition or trigger, such as “killed by mother and brother across three rebirths.”
  - **Theme**: central conflict or values clash, such as “extreme preference for sons.”
  - **Central action**: what the protagonist does, such as “lets mother and brother destroy themselves.”
  - Combine into one sentence, such as “A girl killed by her mother and brother across three lives lets them destroy themselves in the fourth.”
- Write a 200–500-Chinese-character **story summary**.
- Identify POV: first/third person or omniscient.
- Identify chronology: linear, interpolation, flashback, or alternating timelines.
- Divide the text functionally into four to six parts. Include opening, development, climax, and ending; add turn or transition as needed. Record length range and percentage for each.

> **Flexible sections**: some stories have only two or three chapters containing numbered subsections. Analyze by narrative functional unit, not physical chapter.

#### B. Plot-Node Extraction

A plot node is a key event or information release that advances the story.

Use semantic change as the boundary. Record a node when risk, information, relationship, resources, decision, action, or reader understanding changes. If one continuous action chain serves several functions, keep it as one node and explain them in its description. Never split by length or quota. Cover every genuine change without repeating an event to reach a target number.

For every node:

| Field | Description |
|------|------|
| Number | Strict chronological order |
| Type | Emotional/information/conflict/turning/dialogue/atmosphere node |
| Description | Objective plain statement of what occurs; no narrative-framework language |
| Source quotation | Direct quotation ≤300 Chinese characters |
| Emotion | Type + intensity from -9 to +9 |
| Characters | Full names |
| Technique | Technique used, when present |

### Stage 3: Emotional Arc + Explosive-Beat Analysis

#### A. Emotional Curve

Generate the curve from plot nodes. Plot points only where emotional position, expectation, or pressure actually changes. Do not manufacture a point for every section when a complete task, reasoning, craft, or waiting chain contains no independent emotional turn.

Extract:

- Starting emotion
- Pattern: rise/fall/wave/V/inverted V/staircase/cliff/compressed spring
- Highest and lowest points with percentage positions
- Directional difference from beginning to end
- Number of positive/negative alternations

#### B. Explosive-Beat Analysis

| Dimension | Question |
|------|------|
| Setup | What makes readers care, and within how many characters? |
| Accumulation | What stores emotional energy, and for how long? |
| Delay | Is release delayed through information gaps, misunderstanding, or suspense? |
| Detonation | Which exact sentence releases the emotion? |
| Aftershock | Do reactions continue across several characters? |
| Impression | What remains in memory afterward? |

**Stacked detonations**: a surface detonation such as death or separation may erupt first, followed in its aftermath by a deeper truth or perceptual overturn. Record:
- Whether stacking exists.
- What the surface and deep detonations are.
- Where their combination creates more than additive force.

**Chained detonations**: wealthy-family revenge and public-opinion reversal may contain several independent but related explosions. Record:
- The number and nature of each.
- Whether they escalate or satisfy in parallel dimensions.
- Whether spacing avoids emotional rupture or fatigue.

#### C. Anticipation Analysis

Track expectation state section by section using the Stage 3C table in output-templates.md.

Rule: no more than two sections without creating an expectation and no more than one without advancing the central expectation.

### Stage 4: Reversal Design + Writing Techniques

#### A. Reversal Analysis

**Preexisting-reversal check**: identify any lie or misjudgment that existed before the story chronology.

> **No-reversal/retribution stories**: revenge and rebirth fiction may lack a conventional reversal; satisfaction comes from the antagonist receiving consequences. Skip reversal mechanics and analyze “retribution design”: each wrongdoing → corresponding consequence → source of satisfaction. Ideally the consequence mirrors the wrongdoing precisely.
>
> **Active retribution vs. self-destruction**: distinguish a protagonist's trap that makes the antagonist expose themselves from antagonists turning on one another and destroying themselves. The second is more realistic but less satisfying.

When a reversal exists, analyze:

- At least two setup clues with source locations
- Direction of misdirection
- Method of truth revelation
- Retrospective fairness
- Percentage position
- Setup-to-release ratio

**Reversal chain**: list each consecutive reversal in order:
- Each reversal: type + trigger + changed reader perception.
- Causality between reversals, including how an earlier reversal prepares a later one.
- Overall effect of the chain: escalation, stacking, or surprise.

**Nested-reversal test**: Reversal A must explain or deepen Reversal B. Remove any layer; if the others remain fully intact, the layers lack causality and are merely stacked.

**Foreshadowed reversal**: some reversals reuse information given at the opening, whose meaning changes after the truth. Record its original location, first-reading meaning, and later meaning.

#### B. Writing-Technique Analysis

| Dimension | Analysis |
|------|----------|
| POV strategy | Effect of person, narrative distance, reliability |
| Dialogue | Density, subtext, patterns |
| Time control | Jumps, compression, parallel editing |
| Information control | Reader knowledge vs. character knowledge; timing of concealment/reveal |
| Sensory anchoring | Distribution, dominant sense, switching |
| Sentence rhythm | Long/short alternation, acceleration/deceleration, placement of key lines |
| Contrast | Characters, before/after, environment |
| Imagery/objects | Repeated objects, images, symbols |
| Omission | What is unwritten and implied |
| Weaponized expertise | Protagonist uses profession in revenge or conflict: perfumer uses scent, AI engineer uses AI, lawyer uses law. Specific expertise creates credibility and novelty |
| Countdown | A defined limit such as ten days, five hours, or one minute creates urgency; each update catalyzes emotion |
| Dual viewpoint | Experience one event through two characters: pain through A, remorse through B. Readers revise judgment and cannot choose a simple side |
| Bullet-comment interaction | In-story “reader comments” become characters by supplying tasks, criticism, and previews; commentary may have its own arc |
| Cute contrast | Character performs one identity but exposes their nature; every “failed performance” increases affection. Identify the repeated escalation |

For each technique, record location, effect, and reuse conditions.

### Stage 5: Characters + Opening and Ending

#### A. Character Extraction

Short fiction usually contains three to five characters, each carrying several functions.

**Two-dimensional classification**:

Narrative role—position in story:

- **Protagonist**: first-person viewpoint or central focus
- **Major supporting character**: substantial presence and independent arc
- **Functional character**: specific narrative role such as catalyst or foil

Action role—how the person moves:

- **Active**: initiates plot and makes decisive choices
- **Passive**: is moved by plot and endures
- **Transforming**: changes from passive to active or the reverse

> One person can be protagonist + passive, or transform from passive to active. Label dimensions independently.

**Dual protagonists**: Identify when both people have full emotional arcs, the story divides into A- and B-centered sections, and readers strongly empathize with both. Mark each as protagonist and state their chapter ranges.

| Field | Description |
|------|------|
| Name | Full name |
| Classification | Narrative {protagonist/major support/function} + action {active/passive/transforming} |
| Personality | Infer from behavior, not labels |
| Inner conflict | Central psychological conflict, not external event |
| Key lines | One or two representative lines |
| Arc | Beginning → turn → end, with triggers and positions; mark “flat” when absent |
| Function tags | Narrative functions |

**Seven function tags**:

| Tag | Definition | Example |
|------|------|------|
| Emotional carrier | Main focus of reader empathy | First-person protagonist |
| Source of oppression | Produces negative emotion | Cold/controlling male lead |
| Reversal trigger | Activates the main reversal | Third party in an abduction |
| Moral anchor | Represents ordinary values | Concerned elder |
| Foil | Contrasts with protagonist | Gentle support vs. cold protagonist |
| Catalyst | Moves plot without direct participation in central conflict | Connecting/warm character |
| Self-destructive | Conduct causes personal ruin | Son-favoring mother or obsessive relative |

A character may carry several tags.

#### A2. Relationships

Extract relationships and evolution from plot nodes:

| Field | Description |
|------|------|
| Pair | A ↔ B, full names |
| Essence | One-sentence core, such as one-way dependence → equal refusal |
| Evolution | Section N: State A → Section M: State B, with trigger |
| Emotional contribution | Contribution to the emotional arc |

- Extract only pairs with direct interaction or explicit emotional description.
- Keep the final state and record history in evolution.
- Identify exact turn locations and causes.

#### B. Opening Analysis

- First three sentences quoted
- First 50 Chinese characters: conflict or anomaly?
- First 100: does reader understand the central conflict?
- Hook type: suspense/conflict/contrast/identification/information gap
- Opening intensity, 1–10
- Identification: strong immediately / medium after several paragraphs / weak
- Information density: high/medium/low
- Voice distinction: strong after one line / medium / weak and homogeneous

#### C. Ending Analysis

- Quote or summarize final paragraph.
- Type: satisfying HE / regretful BE / open / reversal aftertaste / omission.
- Intensity 1–10. Passing references: tragedy ≥8, wish fulfillment ≥7, healing ≥6, lucid satisfaction ≥5, shocking reversal ≥7, and **lingering BE ≥8**.
- Emotional landing: what readers think upon leaving.
- Aftertaste design.
- Desire to recommend.
- Closure: whether all hooks resolve.
- Values: final statement, such as “love is seasoning, not necessity.”

#### D. Opening/Ending Echo

| Echoed element | Opening location | Ending location | Method | Effect |
|----------|----------|----------|----------|------|

**Rereading discovery**: identify opening statements that acquire a completely different meaning after the truth. Record the line and both meanings.

#### E. Hook Resolution

| Hook | Planted | Type | Resolved | Method | Status |
|------|----------|------|----------|----------|------|

Mark unresolved hooks as `留白` or `遗漏`.

### Stage 6: Overall Assessment Report

Synthesize all stages:

- Story-kernel assessment
- Five scores: opening attraction, emotional pull, reversal design, pacing, ending aftertaste
  > **Alternative dimensions for sweet romance/comedy**: replace reversal design with cute-contrast density and emotional pull with sweetness curve. Score opening attraction, sweetness curve, cute contrast, pace, and aftertaste.
- Explosive-beat potential + discussion potential
- Resonance layers
- At least three reusable structures with use cases
- Concrete actions for writing the same type

## Plot-Node Extraction Rules

### Six Node Types: Do Not Invent Others

| Type | Definition | Recognition |
|------|------|----------|
| Emotional | Clear internal emotional change | Emotion wording, changed behavior, interior monologue |
| Information | New knowledge reaches reader or character | Revelation, discovery, being told |
| Conflict | Direct confrontation | Opposition, refusal, threat |
| Turning | Story direction changes | Plot redirects |
| Dialogue | Dialogue/subtext carries key information | New information or changed relationship |
| Atmosphere | Major environmental/atmospheric shift | Scene, time, or season changes |

### Quality Requirements

1. **Objective description**: record only what happens.
   - Prohibited: “沈暮月心碎地听到了真相.”
   - Correct: “沈暮月听到‘私生子而已’，手停在半空.”
2. **Absolute order**: follow the sequence in which events appear in the text.
3. **Precise emotion**: label type and intensity for each node.
4. **Information fidelity**: retain every context-changing detail.
5. **High compression**: summarize one node in one sentence.
6. **Composite merging**: merge consecutive micro-actions serving one emotional/narrative purpose under one N number; count final N numbers.

### Description vs. Evaluation

- Prohibited: “通过这段对话展现了她的坚强.”
- Correct: “她直视霍庭煜说‘我没有义务配合你’.”
- Prohibited: “气氛变得紧张.”
- Correct: “霍庭煜眼神骤冷，周身散发出威压.”

## Writing-Technique Analysis

### POV Strategy

| POV | Effect | Suitable emotion |
|----------|------|----------|
| First person | Intimacy, identification, controllable information | Tragic romance, introspection, interiority |
| Limited third | Identification with observational distance | General |
| Omniscient third | Multiple simultaneous threads | Ensemble, mystery |
| Second person | Extreme immersion | Experimental, psychological horror |
| Nonhuman | Novelty and defamiliarization | System/ghost/animal viewpoint |

Analyze:
- Benefits and costs of the selected POV.
- Information control within the POV, such as unreliable narration.
- Timing and effect of POV switches, when present.
- **Proxy problem**: when the POV character cannot act directly, such as a watching spirit or unconscious observer, a living proxy must perform actions. The proxy's entrance and agency determine credibility.

### Dialogue Techniques

| Metric | Calculation | Meaning |
|------|----------|------|
| Dialogue share | Dialogue characters / total characters | Describe and compare with same-genre/platform samples; no universal threshold |
| Subtext rate | Lines with subtext / total lines | Describe avoidance and information control; direct speech may fit instruction, rescue, or boundary setting, so higher is not automatically better |
| Interrogation dialogue | Count of protagonist question → opponent self-exposure | Record whether questions force choices, expose contradictions, or change relationships; no minimum |
| Information-gap dialogue | Reader knows what character does not | Central in tragic/reversal fiction |

**Dialogue-pattern identification**:
- Interrogation: the protagonist asks questions → the other side is forced to expose itself.
- Suppression: short, forceful lines press relentlessly → the other side becomes hysterical.
- Information gap: the two sides have asymmetric information, with the reader in between.
- Push-pull: characters move closer and then pull away in a repeated cycle.
- Track changes in forms of address, such as `阿虎` vs. `林川`, because they reveal relationship and identity changes. Record the trigger.

### Time Control

| Technique | Definition | Signal |
|------|------|----------|
| Time jump | Skip a period | `三年后`, `五年后` |
| Scene compression | Summarize a long duration | Overview passage |
| Parallel editing | Alternate timelines | A/B lines alternate |
| Flashback chronology | Give result before process | Result first, then causes |
| Flashback scene | Insert a memory | Past scene appears |
| Real-time expansion | Unfold decisive moment second by second | Slow motion at a key scene |

### Information Control

| Moment | Reader knows | Character A knows | Character B knows | Gap |
|------|-----------|-----------|-----------|--------|
| Opening | | | | |
| Before reversal | | | | |
| After reversal | | | | |

### Imagery/Object Tracking

| Object/image | Locations | Meaning each time | Evolution |
|-----------|---------|---------------|---------|

If none recur, state `无明显意象重复`.

**Thematic image cluster**: when several objects point to one theme, analyze their relationship rather than isolating them. Boxing gloves, tattoos, and a storage room may all express “identity imprisonment.” Record shared theme, each angle, and total effect.

### Omission

Identify deliberate omissions:

- Background left to imagination
- Unspoken words through pauses or ellipses
- Skipped process with result given directly
- Open ending without aftermath

## Emotional-Arc Analysis

### Emotion Types

| Type | Signals |
|------|--------|
| Concern | Behavioral detail and endurance |
| Anger | Antagonist conduct and injustice |
| Shock | Reversal and truth |
| Satisfaction | Payoff and punishment |
| Tension | Suspense and crisis |
| Bittersweet pain | Letting go, regret, growth |
| Healing | Care, reunion, being understood |
| Oppression | Compromise and endurance |

### Emotional Intensity Scale

| Value | Corresponds to | Description |
|----|------|------|
| +9 | Extreme satisfaction | Humiliation, domination, ultimate reversal, villain punished |
| +7 | Strong satisfaction | Key evidence and fulfilled expectation |
| +5 | Clear positive | Small victory or warm moment |
| +3 | Mild positive | Small progress or everyday warmth |
| 0 | Neutral | Transition/setup |
| -3 | Mild discomfort | Small setback or grievance |
| -5 | Clear negative | Humiliation, misunderstanding, threat |
| -7 | Strong anguish | Abandonment, betrayal, child mistreated |
| -9 | Extreme anguish | Mortal threat, spiritual destruction, collapse of belief |

> Use -9 to +9 and only odd values plus zero for emotional curves. Opening/ending analysis uses a separate absolute 1–10 intensity scale.

### Curve Shapes

| Shape | Pattern | Genre | Effect |
|------|------|----------|----------|
| V | Pain then satisfaction | Revenge | Extreme contrast |
| Inverted V | Sweet then painful | Bad-ending tragedy | Lingering regret |
| Wave | Alternating | Groveling pursuit | Emotional push-pull |
| Staircase | Progressive escalation | Wish fulfillment | Strong rhythm |
| Cliff | Sudden reversal | Death/reversal fiction | Shock |
| Compressed spring | Long oppression then one release | Patient plotting | Maximum release |
| Double peak | Two climaxes | Complex short story | Layered; both may be painful or different, such as release then acceptance |
| **Hybrid** | Combination | Depends | Name primary and secondary shapes. Sweet/comedy may remain positive throughout as a staircase variant |

## Pacing Analysis

### Metrics

| Dimension | Calculation | Comparison | Meaning |
|------|----------|----------|------|
| Event density | nodes / total characters × 1,000 | Same genre/platform and internal distribution | Judge whether nodes change state; count alone does not prove filler or rushing |
| Dialogue density | dialogue characters / total × 100% | Same genre/platform | Describe tendency; assess function and non-dialogue progression separately |
| Conflict density | conflict nodes / total nodes × 100% | Same genre/platform and pressure sources | Record task, evidence, waiting, spatial, and relationship pressure separately |
| Information density | information nodes / total nodes × 100% | Reader-model changes and consequence space | Assess comprehensibility, changed judgment, and digestion; no universal percentage |

### Pace-Anomaly Detection

| Pattern | Signal | Review question |
|----------|----------|----------|
| Pace collapse | Consecutive units lack state change, causal consequence, or reader-model update | Is the scene building force, completing work, or repeating itself? |
| Pressure overload | Escalations lack choice, loss, response, or consequence | Can readers understand what each changed? |
| Information flood | New facts arrive without verification, orientation, action, or changed meaning | Which facts alter judgment and which form a list? |
| Failed dialogue | Exchange can be deleted or consists only of Q&A, repetition, exposition | Does each round change information, strategy, power, relationship, or action? |
| Dialogue displaces scene | Characters speak without action; space, task, and consequence vanish | Is action or omission needed rather than a percentage cutoff? |
| Reversal overload | New reversal erases the last before it produces choice or consequence | Does each layer have evidence, changed reader model, and perceptible consequence? |

## Character-Extraction Rules

### Short-Form Standard

Extract every named or narratively functional character.

**Must extract**:

- Named character of at least two Chinese characters who speaks or advances plot
- Unnamed but recurring character appearing in at least two sections with a narrative function

**Do not extract**:

- Group labels such as “旁人” or “大家”
- Nameless bystanders such as “一个中年人” or “助理,” unless they deliver a key line
- Generic titles blacklisted by the long-form chapter extractor, such as teacher, boss, or master

### Classification

> Use the two dimensions from Stage 5: narrative {protagonist/major support/function} + action {active/passive/transforming}.

### Inner Conflict

| Wrong | Correct |
|------|------|
| She was abandoned by Huo Tingyu, an external event | She longs to be loved but learns to survive without love |
| He treats her poorly, a behavior | He controls everything except his own feelings |

### Functional Assessment

| Metric | Question |
|------|------|
| Entrance efficiency | Is the role established at first appearance? |
| Functional density | How many narrative jobs does the character carry? |
| Deletability | Does the story survive removal? If yes, the character is unnecessary |
| Dialogue contribution | Does every exchange advance plot or emotion? |

## Resonance Analysis

### Nine Layers

| Layer | Definition | Focus |
|------|------|----------|
| Emotional | Immediate empathy with current feeling | Where does empathy occur? |
| Values | Agreement with a specific value such as “women should not be defined by others” | What value is conveyed? |
| Experience | Similarity to readers' lives | What experiences invite identification? |
| Social phenomenon | Connection to widespread issues | What phenomenon is reflected? |
| Cultural | Connection to tradition | What cultural memory activates? |
| Universal values | Broad human ideals such as freedom, dignity, love | What universal theme is touched? |
| Philosophical | Reflection on life or existence | What thought is triggered? |
| Emotional depth | Persistent effect days after reading | Does emotion endure? |
| Character depth | Understanding and accepting complexity | Are characters dimensional? |

Rate each as extreme / strong / medium / weak / none. A short story has spread potential only when at least three layers reach strong or medium.

> Distinguish immediate emotional empathy from persistent emotional depth, and agreement with a specific story value from broad universal-value resonance.

### Explosive-Beat Potential

Assess:
- What is the central explosive beat?
- Is its setup sufficient?
- Is its release fully delivered?
- Is it shareable?

### Discussion Potential

Assess:
- What will readers discuss after finishing?
- Is there a controversial point?
- Does it prompt self-reflection through identification?
- Does it create room for “What would I do?” discussion?

## Structure Quick Reference

| Structure | Pattern | Suitable emotion |
|------|------|----------|
| Three-act reversal | Setup → escalation → reversal | Shock, lingering regret |
| Alternating lines | Visible and hidden plots alternate | Suspense, revelation |
| Time jump | Past and present interweave | Regret, growth |
| Nested reversal | Multiple layers | Surprise, cerebral pleasure |
| Dialogue-driven | Dialogue advances narrative | Tragic romance, interpersonal conflict |
| Monologue | First-person interiority | Healing, reflection |
| Rebirth reversal | Protagonist behaves oppositely after rebirth → opponent destabilizes | Satisfaction |
| Spirit observer | Spirit watches after death → truth emerges | Regret, anger |
| Dual-rebirth contest | Both reborn → information warfare | Tension, exhilaration |
| Patient plotting | Surface obedience conceals plan → counterattack | Oppression → maximum release |
| Nonhuman viewpoint | Ghost/system/spirit observes people | Novelty, horror, satisfaction |
| Growth and redemption | Help during suffering → self-redemption → shared future | Warmth, bittersweet healing |
| Public-opinion reversal | Multiple opinion reversals → evidence counterattack → truth | Satisfaction, shock |
| Cold revenge | Calm evidence gathering → decisive action → clean exit | Satisfaction |
| Countdown farewell | Time-limited departure → countdown → final separation | Bittersweet regret and clarity |

### Matching Analysis

1. Identify the primary structure.
2. Most strong short stories are hybrids. Label primary + secondary, such as spirit observer (primary) + compressed spring (secondary). Primary determines narrative framework; secondary determines emotional rhythm.
3. Identify structural innovation, such as AI system × revenge.
4. Assess whether the structure best fits genre and emotional objective.

- **SKILL.md** = routing logic + pipeline summary: Phase 1 interaction and length routing, Stage 2–6 table, and acceptance.
- **This file, material-decomposition.md** = methodological detail for Stages 2–6, including plot nodes, techniques, emotional line, pace, and resonance, plus the **sole authority for quality standards**, thresholds, values, and calculations.
- **output-templates.md** = exact Markdown output templates for every stage, per-item quality checklists with `[BLOCK]`/`[WARN]`, and the Stage 6 `_meta.json.structure_counts` template; numeric values come from this file.
- **output-contract.md** = output-contract SSOT defining Stage-to-file mapping, the `_meta.json` schema including `structure_counts`, downstream `story-short-write` consumption, and acceptance integration. Its copy in `story-short-write` is byte-identical and guarded by `scripts/check-shared-files.sh`.
- **source-story-quality.md** = source-quality checklist for short-story deconstruction; numeric values come from this file.
- **analysis-report-style.md** = evidence-chain and expression gate for the report itself. It scans `拆文报告.md`, not the source story.

See “Reference Materials” in SKILL.md for load timing of comparison-standard files.
