Load this during Phases 3–4 when controlling pace. Covers progression design, emotional-module formulas, structured sequence design, climax categories, opening formulas, and anticipation management.

## Three-Step Progression Design Method

### Step 1: List the Starting Point

List the protagonist’s current identity, class, status, and resources.

### Step 2: List the Destination

List the gains and improvements achieved by the end of the volume or stage.

### Step 3: Reverse-Engineer the Emotional Gap

| What Is Gained | What to Set Up |
|----------|----------|
| Key item | Supporting characters emphasize its scarcity + others seek it in vain + demonstrate its effects |
| Higher status | Show the power associated with that status + highlight differences in treatment between ranks |
| A character’s help | Demonstrate that character’s value + show how others treat them |

### Nested Progression Loops

Challenge Instance A → acquire Item B → achieve Goal C → advance → challenge Instance D.

Core: **The protagonist is always progressing or preparing to progress. After advancing, they can do something previously impossible.**

### Reinforce Contrast from Multiple Angles

| Dimension | Before | After |
|----------|--------|--------|
| Numbers / combat power | Basic attack deals 300 damage | Basic attack deals 650 damage |
| Number of skills | Can only dodge after using one skill | Still has a second skill |
| Rank / status | Nobody pays attention | People approach proactively |
| Social treatment | Mocked | Surrounded by applause and amazement |
| Resource access | Painfully saves up materials | High-value information arrives unsolicited |

### Specific Techniques for Progression Fiction

**Setup before and after advancement**:
- Before: Establish disparities in treatment and the difficulty of acquiring resources
- After: Demonstrate changes across multiple dimensions—combat power, treatment, relationships, and resource access

**Limit the number of advancements**: Ideally, the protagonist advances no more than three times; improve quality instead of piling up quantity.

**Immediate and delayed feedback**:

| Feedback Type | Function | Example |
|----------|------|------|
| Immediate feedback | Give a small reward for every action to sustain motivation | Monsters drop loot |
| Delayed feedback | Accumulate progress until a major reward erupts | Level up when experience fills |

**Connect progression with familiar concepts**: The more ordinary, the easier it is to understand—grow stronger by breathing, sleeping, or having many children.

**Three ways to extend the story after advancement**:

| Method | Execution |
|------|------|
| Expand the map | Raise the ceiling of the power system and create a multilayered world |
| Suppress levels + add complexity | Expand one promotion goal across three plot events |
| Change the writing core | Shift from progression to characterization through supporting-character tracks and subplots |

## Emotional-Module System

### Levels of Abstraction

| Level | Name | Content |
|------|------|------|
| Level 0 | Specific story | The source’s complete plot |
| Level 1 | Classic plot | Remove description, retain core material |
| Level 2 | Story configuration | Remove all material, leaving only the logical direction |
| Level 3 | Dramatic unit | Abstraction of drama—the broad dramatic direction |
| Level 4 | Emotional module | Abstraction of emotion—what readers want to see |

### Dramatic Unit vs. Emotional Module

| Dimension | Dramatic Unit | Emotional Module |
|------|---------|--------|
| Essence | Logical structure that creates drama | The reader’s emotional desire |
| Wear | Wears out (too much of one structure stops working) | **Does not wear out** (heroic rescues have lasted since the age of epics) |
| Example | A directional framework such as “misunderstanding → conflict → reversal” | A desire such as “readers want to see humiliation or regret” |

One-sentence test: If it can be drawn as a flowchart, it is a dramatic unit. If it can be written as “readers want to see XX,” it is an emotional module.

### How to Use Them

1. **Reconstruct**: Keep the material while changing the story configuration. Best for long-form fiction and essential at million-character scale.
2. **Fine-tune**: Use a classic plot directly and refine it through characterization. Best for short fiction.

## Common Emotional-Module Formulas

### Heroic Rescue

```
关系平平或恶劣 + 危机产生 + 化解危机 + 关系质变
```

Core: The payoff of a qualitative change in the relationship. Applicable to any positive transformation in a character relationship. Career-first story → emphasize the special advantage; romance-first story → emphasize the relationship change.

### Showing Off

```
被打压嘲讽（可选）+ 展示能力 + 打造落差 + 震惊
```

Core: Contrast—a before-and-after reversal plus parallel comparison.

Five modes: create a comparison, show off and humiliate, self-deprecation + praise from others, dismissal by others + their humiliation, and demonstrate indirectly through someone else.

### Small Stake, Great Gain

```
小代价 + 入水之鱼的环境 + 获得大收获
```

Core: The psychology of “getting a bargain.” The greater the multiple between cost and return, the stronger the payoff. The process needs randomness + protagonist agency.

### Turning Stone into Gold

```
不被看好的某物/某人 + 主角改造 + 产生价值
```

### Recognizing Hidden Value

```
主角已知价值 + 众人不看好 + 唯有主角知晓的情报 + 真相揭晓 + 众人震惊
```

### Accidental Success

```
暗示宝物重要性 + 主角在错误方向上努力 + 偶然获得宝物 + 众人震惊
```

### Youthful Passion

```
主角团面对强大恶劣环境 + 明知不可为仍然努力 + 打破困境
```

### Taking Charge in a Crisis

```
危机超出现场能力 + 配角穷尽办法无法解决 + 主角接手 + 完成任务
```

### Combining Emotional Modules

| Combination | Effect |
|------|------|
| Small Stake, Great Gain + Heroic Rescue | Double payoff |
| Turning Stone into Gold + Showing Off | Suppression followed by an eruption |
| Youthful Passion + Artifact Chooses Its Master | Classic formula |
| Taking Charge in a Crisis + Showing Off + Heroic Rescue | Demonstrates power during a crisis |

## Structured Sequence and Pacing Design

### Standard Four-Chapter Sequence Structure

3 million Chinese characters ≈ 40–50 units → 4–5 sequences per unit → about four chapters per sequence.

**Standard structure: one sequence across four chapters**:

| Chapter | Function | Key Point |
|----|------|------|
| First half of Chapter 1 | Identification: daily life + interaction with familiar characters | N+1 principle |
| Second half of Chapter 1 | Information gap: show the opponent or dilemma | Cut away to reveal it |
| Chapter 2 | Intensify the push and pull through supporting characters’ reactions | The ending must have the protagonist begin the display |
| Chapter 3 | Deliver: fully realize the payoff | The easiest chapter to write |
| Chapter 4 | Bridge forward | Conclude or open the next goal |

**Inside-the-circle principle**: First draw a circle around the content; throughout the book, write only material inside it that relates to the core selling point.

### Iron Rules for Climax Pacing

- Major climax: complete within 7–10 days (two chapters daily / about 14 chapters); readers resent anything beyond 10 days
- Minor climax: complete in about three days
- After the climax: use 1–2 slice-of-life transition chapters

### Three Solutions for Transitions Between Stages

1. **Plant a hook during the climax**: Place the next segment’s hook amid the spread of the current climax
2. **End with a goal**: Give the protagonist a clear next-stage goal at the end of a segment
3. **Continuous small anticipation points**: Keep placing small hooks throughout transition chapters

## Climax Categories and Reverse Engineering

### Two Major Types of Climaxes

**1. Real-world climax** (social topics): road rage, infidelity, bullying, and so on. Do not copy them directly; push the emotion to its limit. Usually placed at the opening or the point when paid publication begins.

**2. Story climax** (eight types):

| Category | Typical Form |
|------|------|
| Emotional resonance | Passion, fundamental emotions, romance |
| Sensory impact | Grand fantasy spectacle, horrifying imagery |
| Conflict eruption | Struggles for power, betrayal for profit |
| Advancement rewards | Realm breakthrough, equipment acquisition |
| Contrast and astonishment | Showing off and humiliating, identity reveal |
| High-intelligence revelation | Mystery deduction, scheme revealed |
| Grotesque and uncanny | Rules-based horror, Cthulhu mythos |

### Four Elements to Reverse-Engineer from a Climax

After defining the climax, work backward through: ① characters ② background ③ story lines ④ emotional evolution. The last two must be combined.

## Opening Formulas

### Golden Five-Chapter Formula

| Chapter | Content | Function |
|----|------|------|
| Chapter 1 | Transmigration / background / characterization / special advantage / establish desire | Build foundational understanding |
| Chapter 2 | Clarify the main plot | State the premise |
| Chapter 3 | Demonstrate the special advantage’s power | Run the advantage |
| Chapter 4 | Build hostility / establish opposing sides / create an information gap / lay groundwork | Build anticipation |
| Chapter 5 | Successfully show off / trigger a new event | Complete the first payoff loop |

### Opening-Trimming Method

1. Organize the conflicts in the opening’s first level-one structure
2. Connect every piece of introductory and lyrical text upward, one by one—try to link it directly to the conflict
3. If the connection requires several layers of logic → **ineffective information; delete it**
4. Do not name supporting characters who have no later role

### Minimum Opening-Pace Standards

| Requirement | Standard |
|------|------|
| Payoff / anticipation appears | Must appear within 1,000 Chinese characters |
| Combat | Do not open Chapter 1 with a fight |
| Romance target | Must appear within the first level-one structure |
| Demonstrating the special advantage | It resolves the first conflict, and the protagonist actively chooses to use it |

## Diagnosing and Repairing Broken Anticipation

### Four Root Causes

| Cause | Reader Reaction |
|------|----------|
| Excessively delayed gratification | “When will anything satisfying finally happen?” |
| Mishandled map change | “Everything I was anticipating is gone” |
| Core hook repeated too often | “This again? It is boring now” |
| Unsatisfying payoff | “That’s it?” |

### Principles for Sustained Anticipation

**Core formula: anticipation-building speed > anticipation-breaking speed**

1. Plant clues to the next goal before completing the current one
2. Introduce new anticipation quickly after satisfying the current expectation
3. Cut subplots that do not serve the core hook
4. Keep the protagonist’s goal clear at all times
5. Differentiate repeated uses of the same core hook

### Emergency Fixes for an Anticipation Dead Zone

| Technique | Execution |
|------|------|
| Transition to villain POV | Show the villain acting and create an information gap |
| Sudden accident | Force an unplanned event into the story |
| Supporting-character leverage | Use a supporting character’s crisis to recreate urgency |
| Windfall | Give an extra reward far beyond expectations |

## Matching Selling Points to Reader Needs

### Selling-Point Drift Theory

The root cause of collapse is often “selling-point drift”—the need satisfied by the payoffs has diverged from what readers came to see.

**Needs inventory**: family love, romance, friendship; fantasies of becoming important or gaining something without work; respect, recognition, and understanding; punishing evil and rewarding good; fairness; superiority; adventure; curiosity; growth; acquisition; violence; security; novelty; nostalgia; making up for regrets.

**Blockbuster formula**: Hold onto one need and never drift away from it.

### Two Layers of Selling Points

- **Genre selling point**: Why do readers consume this genre?
- **Book selling point**: Why do readers consume “this particular book”?

Self-check: If the payoffs favor another genre’s selling point, the story has gone off topic.

## Combat-System Design

### Turn-Based Card Approach

Each turn generally allows only one “card.” When using a “combo,” no more than one card should be unfamiliar to readers.

### Cost-Benefit of Power Matchups

| Matchup Type | Difficulty | Effect | Rule |
|----------|------|------|------|
| Strong vs. weak | Easy | Good | Use often |
| Weak defeats strong | Hard to write | Requires setup | Use sparingly |
| Strong vs. strong | Hardest | Best | At most once in a mid-sized story |

### Power-Setting Rules

- A high level implies high status or far-reaching influence
- High-level combat must feel “epic”
- Fighting across a major realm gap requires a plausible explanation

## Battle-of-Wits Configuration (Three-Step, Two-Track Method)

1. The villain creates a three-step plan (goal → means → timeline)
2. The protagonist has an existing plan
3. Their plans entangle each other

Ways to entangle them: competition for resources, threats to interests, indirect collisions.

Key point: The villain also adjusts the plan based on observations; use an information gap to make the villain misjudge.

## Creative Support Methods

### Adaptation Method

1. Define the target type of conflict and search the plot-archetype library
2. Break the matching plot into a detailed outline on the left, place your own circumstances on the right, and adapt point by point
3. Verify that the adaptation fulfills the emotional goal, connects to the main plot, and contains no logical holes

### Derivative-Fiction Outlining

Read the source → collect materials → extract information, emphasizing impressive presence and extreme emotion → create derivative material by breaking apart and recombining it.

### Triple-Repetition Loop

- **Repeat the appeal**: Identify what readers want and write it relentlessly. Boundary: Adjust after delivering the same appeal three consecutive times without differentiation
- **Repeat the character**: Repeat the same behavior in different settings
- **Repeat the formula**: Keep the basic template while changing the setting

### Minimalist Outlining

Use the progression system itself as the outline. Each volume = one level: entry requirement → core challenge → boss battle → completion reward.

## Quality-Control Checklist

After designing the pacing, check every item:

- [ ] **Sense of progression**: Are the starting point and destination clear? Has the emotional gap been set up adequately?
- [ ] **Progression loop**: Is the protagonist “always progressing or preparing to progress”? After advancing, do they demonstrate something previously impossible?
- [ ] **Comparative demonstration**: Are there at least three dimensions of contrast before and after advancement?
- [ ] **Emotional module**: Is the current sequence’s emotional module clear? Does it complete the full formula?
- [ ] **Sequence structure**: Does each four-chapter sequence complete identification → information gap → push and pull → delivery → bridge forward?
- [ ] **Climax pacing**: Is the major climax contained within 7–10 days? Is the minor climax about three days? Is there a slice-of-life transition after the climax?
- [ ] **Stage transition**: Does the end of the climax plant a hook or establish a new goal?
- [ ] **Opening check** (if applicable): Do the first five chapters follow the golden five? Is there a payoff or anticipation point within 1,000 Chinese characters?
- [ ] **Anticipation**: Is anticipation built faster than it is broken? Is any anticipation dead zone left untreated?
- [ ] **Selling-point consistency**: Do the payoffs satisfy the needs promised by the book’s selling point, or have they drifted into another genre?
- [ ] **Combat / battle of wits** (if applicable): Is the matchup type appropriate? Does the battle of wits use information gaps and entangled plans?
- [ ] **Repetition boundary**: Has the same appeal delivered the same emotion more than three times without differentiation? Does it need adjustment?
