# Core Outlining Methods

Load this when building the outline in Phase 3. Covers outline creation, structural levels, node design, and practical detailed outlining.

## Decision Guide: Which Method to Use Now

| Your Current Outline Stage | Method to Use |
|--------------------|------------|
| Just starting the outline | Five-step outline creation method |
| Have a framework and need to refine it | Node-design method + three-layer structure |
| Designing a single volume | Eight-node story structure |
| Creating a detailed or chapter outline | Detailed and chapter outlines |
| Stuck / working backward | Extrapolation and reverse-engineering methods |

## Story-Structure Levels

| Level | Characteristics | Best For |
|------|------|------|
| Level 1 | Loosely connected episodic stories linked by time, ending in a major climax | Beginner |
| Level 1.5 | Episodic stories linked by logical clues that point toward a central goal | Intermediate |
| Level 2 | Small climax → unexpected downturn → upward reversal → major-climax chain | Advanced |

## Five-Step Outline Creation Method

### Step 1: Define the Climax

The climax has absolute priority: the largest conflict, the most characters present, and the strongest emotional fluctuation.

Checklist:
- [ ] Is it the volume’s largest conflict?
- [ ] Does it feature the most characters?
- [ ] Does it closely align with the stage goal?
- [ ] Does it create the greatest emotional fluctuation for readers?

### Step 2: Define the Episodes

Each episode = the protagonist uses the special advantage to deliver a payoff. Repeating one type creates a plot formula; grouping formulas with a logical relationship creates a plot-formula chain.

Requirements:
- Every episode must demonstrate a different use of the special advantage
- Adjacent episodes may not use the same special-advantage logic
- Episodes must have causal relationships with one another

### Step 3: Organize Story Lines and Plant Information

Manage eight story lines simultaneously and mark when each element will be planted:

| Story Line | Content | What to Plant |
|--------|------|----------|
| Map line | Hierarchical locations | When the new map unlocks |
| Faction line | Factions matched to maps | Where faction conflict erupts |
| Character line | Characters grouped by type | When new characters appear |
| Special-advantage line | Items / skills acquired | Ability-upgrade nodes |
| Worldbuilding line | Rules of the world | When each rule is revealed |
| Conflict line | Conflicts placed in a network | Conflict-escalation chain |
| Collection line | Materials / clues collected | Progressive collection tiers |
| Romance line | Relationship progression | Intimacy-upgrade nodes |

### Step 4: Define the Opening Stage

Build the opening in this order:

```
情节钩子 → 迅速陷入异常状态 → 获得/介绍金手指 → 矛盾/欲望出现，主角运转金手指 → 目标建立
```

The opening must plant these sources of anticipation: a new goal or direction of conflict escalation, hints of increasing strength, resource upgrades, romantic progression, expansion of the relationship network, greater disorder, and new clues or premise elements.

### Step 5: Define the Ending

Checklist:
- [ ] Resolve the main-plot and subplot climaxes and show their consequences
- [ ] Give the protagonist sufficient rewards + a bonus reward for the next stage
- [ ] Give the volume’s characters appropriate outcomes
- [ ] Slow the pacing
- [ ] Set up the next volume

## Plot Quality Control

### Plot-Similarity Check

To determine whether two plots are too similar, compare their confrontation or conflict type, use of the special advantage, segments in the plot chain, and ending.

### Plot-Fit Check

| Dimension | Check |
|------|----------|
| Stage fit | Does the plot or romance progress fit this volume’s stage? |
| Setting fit | Is the setting included in this volume’s setting list? |
| Character fit | Are the combination, relationships, and behavior of the characters consistent? |

### Constraints (Mandatory)

- Temporal-spatial connection : logical connection >= 1:3 (for every causal advance, include at least three scene advances)
- The emotional value of later plot events cannot be significantly lower than earlier ones
- Never use the same special-advantage logic consecutively
- Separate similar plot formulas with at least three plot events of different types

## Node-Design Method

### Core Framework (Start → Destination → Key Nodes)

- **Starting state**: The protagonist’s initial condition (untalented / poor / weak)
- **End state**: The protagonist’s final condition (invincible / richest / strongest)
- **Nodes**: Key growth points that keep the story moving toward the destination

### Design Principles

- Make the start and destination as dramatic as possible
- Qualifiers: one rises while the other falls—the good gets better, and the bad gets worse
- Genre = the means by which the protagonist moves from the start to the destination
- Once the nodes are defined, the outline is their arrangement

### Practical Node-Design Steps

1. Define the protagonist’s starting and final states
2. Break down the paths required to reach the destination (realm-progression line / power-growth line / collection line, and so on)
3. Define subnodes for each line
4. Fill the spaces between nodes with stories

## Outline System

### Three-Layer Outline Structure

| Layer | Content | Flexibility |
|------|------|--------|
| Master outline | Main direction of development, a few hundred words | Must be upheld |
| Plot outline | Complete, relatively detailed story lines | May change moderately |
| Detail outline | Bursts of creativity, dialogue, small scenes | Completely flexible |

If the plot drifts from the master outline, you must be able to pull it back. More constraints often produce better stories.

### Three Ways to Write an Outline

| Method | Best For | Core Execution |
|------|----------|----------|
| Map-based | Eastern fantasy | Track progress by map changes, noting power changes, supporting characters, major events, and payoffs |
| Volume-based | Intermediate work | Divide volumes by main plot nodes; define a start, destination, and major nodes |
| Fill-in framework | Early creation | Build the framework first, then fill it with content |

### Outline Design Priorities

1. First define the core creative idea → identify the core selling point
2. Define the main plot from that selling point; derive the special advantage to support the main plot
3. The special advantage must serve two functions: empower the protagonist + continually create goals that advance the main plot
4. If the special advantage drifts from the core selling point, the entire book has drifted and must be corrected

## Detailed and Chapter Outlines

### Detailed Outline

- Detailed outline : main text = 1:2.5–1:3
- Do not expand specific events; focus only on purpose and effect
- Mark every node as “write in detail” or “summarize”
- Core purpose: Make the intended purpose and effect easy to locate during later drafting

### Chapter Outline

- If the master and detailed outlines are sufficient, a chapter outline is unnecessary
- Write a rough outline around key events (one key event takes about 3–5 chapters)
- Mark hooks, foreshadowing, and writing goals

### Notes on Discovery Writing

- When drafting on a rolling basis, do not over-detail the outline; preserve room for adjustment
- The outline is dynamic; key nodes only need to develop around the core hook
- After writing, check whether the protagonist’s current action relates to the goal and whether the new chapter creates anticipation for what follows

### Climax-Driven Outlining

- Design one major climax every 100,000 Chinese characters
- Define the major climax in advance (describe it clearly in 200–300 Chinese characters), then fill the preceding 50,000–60,000 with smaller plots
- Every smaller plot must advance the romance arc or relate to the major climax
- Practical limit: about 400,000–500,000 Chinese characters

## Eight-Node Story Structure

A universal structure for long-form web fiction that can be applied to each volume or major arc. A node may span many chapters.

### Node Reference

| Node | Core Task | Share | Chapters | Pace |
|------|---------|------|------|------|
| 1. Opening | Hook readers and establish anticipation | 5–10% | 1–2 chapters | Fast |
| 2. Development | Advance the plot through escalating events and lay groundwork | 30–40% | 5–15 chapters | Moderate |
| 3. Turn One | Break expectations and raise tension | 5–10% | 1–3 chapters | Fast |
| 4. Turn Two | Raise the stakes and deepen the dilemma | 5–10% | 1–2 chapters | Fast |
| 5. Climax | Direct confrontation over the central conflict | 10–15% | 2–4 chapters | Extremely fast |
| 6. Conflict Outcome | Resolve the conflict and let readers breathe | 10–15% | 2–3 chapters | Slow |
| 7. Turn Three | Deliver the final turn and last surprise | 5–10% | 1–2 chapters | Fast |
| 8. Ending | Resolve the emotional arc and leave an aftertaste | 10–15% | 2–5 chapters | Slow |

### Key Rules for Each Node

**Opening**: Must begin in medias res, with a hook in the first 500 Chinese characters. Never start with background exposition, weather, or scenery.

**Development**: Use 3–5 escalating events, each advancing the main plot. Deliver one payoff every 3,000–5,000 Chinese characters. Plant at least two pieces of foreshadowing.

**Turn One**: Information or an event that changes the situation. Three elements: surprise + plausibility + momentum.

**Turn Two**: An upgraded turn with higher stakes than Turn One and a different type of reversal.

**Climax**: Move quickly with no padding. The protagonist must demonstrate growth.

**Conflict Outcome**: Resolve the main conflict, reveal the spoils through plot rather than a list, and plant a hook for the next arc.

**Turn Three**: Overturn readers’ prediction of the “ending.” It must have been set up earlier.

**Ending**: Resolve the central mystery and emotional arc. Do not resolve every piece of foreshadowing; some negative space leaves a richer aftertaste.

### Payoff-Pacing Formula

- At least one micro-payoff per chapter, according to the chapter’s function: mandatory in high-pressure or advancement chapters; optional in low-pressure, relationship, training, or information-organizing chapters, though every chapter must still give readers a reason to continue—a small curiosity, stage goal, or romantic anticipation
- Resolve one conflict every three chapters
- Deliver one major payoff every seven chapters

### Five Driving-Force Checks (Every 3–5 Chapters)

1. **Source of pressure**: What specific threat does the protagonist face?
2. **Display of power**: Which ability resolves it? Is the method fresh?
3. **Perception overturned**: Which assumption breaks? Is the reversal plausible?
4. **Resource growth**: What was gained?
5. **Mystery growth**: What new question emerges from the resolution?

## Five-Stage Mini-Loop for Wish-Fulfillment Fiction

| Stage | Definition | Key Point |
|------|------|------|
| Stable state / latent crisis | The protagonist is relatively stable while a potential crisis exists | It need not be a good state |
| Crisis trigger | An external force creates the crisis | It must grab attention |
| Breakthrough action | The protagonist uses the special advantage to defeat the scheme | The payoff erupts; extensive setup may build anticipation |
| Reward settlement | A clearly valuable return | Resources / power / reputation / connections / ability |
| New balance and setup | A higher stable state is reached and a new challenge appears | Connects to the next loop |

## Five-Segment Emotional Push-Pull Curve

| Segment | Direction | Content |
|------|------|------|
| Segment 1 | Rise | Setup / the protagonist gains favorable conditions |
| Segment 2 | Turning point + fall | Adverse turn (it cannot be the protagonist’s fault) |
| Segment 3 | Rise | The protagonist acts / an opportunity appears |
| Segment 4 | Turning point + fall | A “feint”—relief first, then an unexpected event |
| Segment 5 | Payoff eruption | The special advantage shines and the goal is achieved |

Use the five-segment curve to plan at a scale of 100,000 Chinese characters; each segment can contain nested curves. When stuck, let the structure reveal the direction.

### Downward-Plot Principles (Mandatory)

- “The protagonist gets all the credit; everyone else takes the blame”
- An emotional downturn must never result from the protagonist’s mistake
- If the protagonist suffers one unit of frustration, revenge starts at tenfold
- After a downturn, repair the emotional deficit through a fortunate accident, help from a benefactor, or a good deed repaid

## Extrapolation and Reverse-Engineering Methods

### Extrapolative Outlining

Extrapolate step by step from the core premise: protagonist’s starting state → family circumstances → plausibility of the special advantage → sources of conflict. Every step may reveal new plot possibilities.

### Work Backward to Design a Chapter Outline

Design in this order: payoff → anticipation point → setup. First decide how readers will feel satisfied, then work backward to determine the groundwork.

Six payoff types: overwhelming ability, goal achievement, inventorying gains, change in attitude, hidden identity / identity reveal, and emotional fulfillment.

### Work Backward from the Truth

1. Define the central truth
2. Break the truth into fragments and plant them in different chapters
3. Make each fragment’s revelation trigger a character action or turn
4. Advanced variation: narrative deception—use information to mislead readers

Best for mystery arcs, identity arcs, past-life/present-life arcs, and stories dense with foreshadowing.

### Reverse-Engineered Anchor Method

Divide the book into two parts: 【worldbuilding】 and 【plot】. First set opening and ending anchors, then ask questions around each anchor; every question generates a line.

Reverse-engineering by volume: First imagine the climax → use it as the anchor and work backward → ask questions → derive the setup and main plot → the detailed outline emerges.

## Chapter-Title Strategy

1. Never use dry summaries (“Beginning,” “Awakening,” “Upgrade”)
2. Use the funniest or most conflict-heavy sentence
3. Even setup chapters need a gimmick in the title
4. Use the chapter’s most boastful line as its title
5. Avoid words such as “analysis,” “situation,” and “game”
